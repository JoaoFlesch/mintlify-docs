### Crie, hospede e distribua páginas da forma que fizer mais sentido para sua operação.

Dentro do TrackUp, o módulo de Páginas foi criado para permitir que você publique praticamente qualquer tipo de página sem depender de ferramentas externas.

Seja para criar landing pages, hospedar páginas próprias, utilizar páginas externas ou até replicar estruturas existentes, o objetivo é simples:

> Centralizar toda sua infraestrutura dentro de um único ambiente.

Ao invés de depender de múltiplas plataformas separadas, o TrackUp permite que você construa e gerencie toda sua estrutura diretamente no seu projeto.

# O papel das páginas dentro do ecossistema TrackUp

Dentro de uma operação de tráfego pago, a página normalmente representa o primeiro contato entre o visitante e sua oferta.

Exemplo:

```text
```

```text
Anúncio
↓
Página
↓
Engajamento
↓
Checkout
↓
Conversão
```

É nela que acontece grande parte da jornada do usuário.

Por isso o TrackUp oferece diferentes formas de publicar páginas dependendo da sua necessidade operacional.

# Quatro formas de criar páginas

Ao criar uma nova página, o TrackUp permite escolher entre quatro métodos diferentes.

Cada método atende necessidades específicas.

---

# 1. Redirect

A forma mais simples de utilizar páginas dentro do TrackUp.

Neste modo, você cadastra uma URL externa e o sistema utiliza essa página como destino do visitante.

Ideal para quem já utiliza hospedagem externa e deseja apenas centralizar sua operação.

Você informa:

- \
  Nome da página\
- \
  URL de redirecionamento\

Exemplo:

```text
```

```text
Página → Landing Principal

URL → https://meusite.com
```

Ideal para:

- \
  Páginas já hospedadas externamente\
- \
  Operações que não precisam migrar infraestrutura\
- \
  Testes rápidos\

→ Continue em **Redirect**

# 2. Builder

Crie páginas diretamente dentro do TrackUp utilizando nosso editor visual.

O Builder foi desenvolvido para permitir construção completa de páginas sem necessidade de código.

Você poderá criar praticamente qualquer tipo de estrutura utilizando:

- \
  Editor visual\
- \
  Blocos prontos\
- \
  Templates\
- \
  Componentes customizáveis\
- \
  Recursos assistidos por IA\

Ao criar a página, ela ficará disponível para edição dentro do Builder.

Você informa:

- \
  Nome da página\

Depois disso, a edição acontece no construtor visual.

Ideal para:

- \
  Landing pages\
- \
  Páginas de vendas\
- \
  VSLs\
- \
  Captura de leads\
- \
  Estruturas totalmente customizadas\

→ Continue em **Builder**

# 3. Upload HTML

Publique páginas próprias enviando arquivos HTML diretamente para o TrackUp.

Essa opção é ideal para usuários que já possuem páginas prontas desenvolvidas externamente.

Você pode enviar:

- \
  Arquivo `.html` único\
- \
  Arquivo `.zip` contendo estrutura completa\

Exemplo:

```text
```

```text
index.html
style.css
script.js
images/
```

O sistema processará automaticamente os arquivos e publicará sua página.

Você informa:

- \
  Nome da página\
- \
  Arquivo HTML ou ZIP\

Ideal para:

- \
  Desenvolvedores\
- \
  Landing pages já prontas\
- \
  Projetos customizados\
- \
  Estruturas exportadas de outras ferramentas\

→ Continue em **Upload HTML**

---

# 4. Clonar URL

Copie a estrutura visual de uma página já existente a partir de uma URL pública.

Esse método permite importar páginas externas e utilizar a estrutura dentro do seu projeto.

Você informa:

- \
  Nome da página\
- \
  URL que será clonada\

Exemplo:

```text
```

```text
Nome → Landing Financeira

URL → https://site-exemplo.com
```

O sistema irá replicar a estrutura da página para utilização dentro do TrackUp.

Ideal para:

- \
  Replicar páginas existentes\
- \
  Criar variações rapidamente\
- \
  Migrar estruturas externas\
- \
  Criar ambientes de teste\

→ Continue em **Clonar URL**

# Qual método devo escolher?

A escolha depende do tipo de operação que você deseja montar.

| Cenário | Melhor opção |
| :-- | :-- |
| Já possui página hospedada externamente | Redirect |
| Quer construir página visualmente | Builder |
| Já possui arquivos HTML prontos | Upload HTML |
| Quer replicar uma página existente | Clonar URL |

---

# Como as páginas se conectam com o restante do TrackUp?

Toda página criada dentro do sistema pode fazer parte da sua operação de tracking.

Fluxo:

```text
```

```text
Campanha
↓
Link de anúncio
↓
Página
↓
Usuário navega
↓
TrackUp registra dados
↓
Usuário avança para checkout
↓
Conversão acontece
```

As páginas fazem parte da infraestrutura central da sua operação.

# Boas práticas

Recomendamos algumas práticas simples.

### Organize páginas por função

Exemplo:

```text
```

```text
Landing Principal
VSL Principal
Página de Obrigado
Pré Checkout
Página de Captura
```

---

### Evite misturar páginas de operações diferentes

Mantenha páginas organizadas dentro do projeto correto.

---

### Escolha o método mais adequado

Nem toda página precisa ser criada no Builder.

Muitas vezes Redirect ou Upload HTML são melhores opções.

---

### Valide antes de enviar tráfego

Sempre teste a página antes de utilizar campanhas pagas.
