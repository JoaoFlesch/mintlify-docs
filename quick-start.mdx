# Configure sua primeira operação

Se esta é sua primeira vez utilizando o Trackup, este guia mostra o caminho mais rápido para configurar sua infraestrutura completa e começar a rastrear campanhas, usuários e conversões corretamente.

Ao final deste processo você terá uma operação pronta para receber tráfego e atribuir vendas de ponta a ponta.

Fluxo padrão:

```text
Anúncio → Link → Página → Checkout → Conversão
```

Todo o ecossistema do Trackup gira em torno dessa estrutura.

# Passo 1 — Crie seu Projeto

Todo projeto representa uma operação independente dentro do Trackup.

Você pode separar projetos por:

- Produto
- Oferta
- Cliente
- Funil
- Operação específica\

Exemplo:

```text
Time → Agência Atlas

Projeto → Produto Financeiro
Projeto → Produto Nutra
```

Para criar:

- Acesse o menu lateral
- Clique em **Novo Projeto**
- Defina o nome do projeto
- Salve\

**\[IMAGEM RECOMENDADA\]**\
\
_(Tela de criação de projeto dentro de um Time.)_

---

# Passo 2 — Configure seu Domínio

Todo projeto recebe um domínio padrão, mas recomendamos conectar seu próprio domínio.

Os domínios serão utilizados em:

- Páginas
- Links
- Redirects
- Builder
- Estrutura pública do projeto\

Recomendação:

```text
lp.seudominio.com
go.seudominio.com
track.seudominio.com
```

Após adicionar o domínio, configure o DNS e valide a conexão.

**\[IMAGEM RECOMENDADA\]**\
\
_(Tela de domínios \+ exemplo de configuração DNS na Cloudflare.)_

---

# Passo 3 — Conecte seu Pixel

Agora conecte a plataforma onde seus eventos serão enviados.

Atualmente suportamos:

- Meta Ads
- Google Ads
- TikTok Ads
- Kwai Ads\

Ao conectar um pixel, o Trackup cria automaticamente os acionadores padrões responsáveis pelos disparos automáticos.

Eventos padrão:

```text
page_view
ad_click
start_checkout
conversion
```

Para configurar:

- Vá em **Integrações → Pixels**
- Clique em **Adicionar Pixel**
- Escolha a plataforma
- Insira as credenciais necessárias
- Salve\

**\[IMAGEM RECOMENDADA\]**\
\
_(Tela de integração de pixel Meta.)_

---

# Passo 4 — Cadastre sua Plataforma de Venda

Agora configure a plataforma responsável por processar seus pagamentos.

Essa integração possui duas funções:

- Gerar parâmetros de checkout
- Receber webhooks de conversão\

Para configurar:

- Vá em **Integrações → Plataforma de Venda**
- Escolha sua plataforma
- Configure parâmetros necessários
- Copie a URL de webhook\

**\[IMAGEM RECOMENDADA\]**\
\
_(Tela de criação de integração com plataforma de vendas.)_

---

# Passo 5 — Crie sua Oferta

A oferta representa o checkout final para onde o usuário será enviado.

Ela conecta o Trackup ao pagamento.

Você irá informar:

- Nome da oferta
- Plataforma utilizada
- URL do checkout\

Exemplo:

```text
Oferta → Produto Financeiro
Checkout → checkout.produto.com
```

Sem uma oferta, não é possível criar links de checkout.

**\[IMAGEM RECOMENDADA\]**\
\
_(Tela de criação de oferta.)_

---

# Passo 6 — Crie o Link de Checkout

Agora vamos criar o link responsável por enviar o usuário ao checkout mantendo todos os parâmetros de rastreamento.

Esse link preserva:

- UTMs
- Click ID
- Session ID
- Dados de atribuição\

Fluxo:

```text
Landing Page
↓
Botão de compra
↓
Link de Checkout
↓
Checkout
```

Para criar:

- Vá em **Links**
- Clique em **Novo Link**
- Escolha **Checkout**
- Vincule a oferta criada\

**\[IMAGEM RECOMENDADA\]**\
\
_(Tela criando link do tipo Checkout.)_

# Passo 7 — Crie sua Página

Agora crie a página que receberá seus visitantes.

Métodos disponíveis:

- Builder
- Templates
- IA por Prompt
- Upload HTML
- Clonar URL
- Redirect\

Recomendação inicial:

```text
Builder + Templates
ou
Builder com IA
```

Para criar:

- Vá em **Páginas**
- Clique em **Nova Página**
- Escolha o método desejado\

**\[IMAGEM RECOMENDADA\]**\
\
_(Tela mostrando todas as opções de criação de página.)_

---

# Passo 8 — Adicione o Link de Checkout no Botão de Compra

Sua página precisa enviar o usuário corretamente para o checkout.

No botão principal da página:

```text
Comprar Agora
```

Configure como destino o **Link de Checkout** criado anteriormente.

Fluxo:

```text
Usuário acessa página
↓
Clica no botão
↓
Trackup preserva parâmetros
↓
Usuário chega no checkout
```

Nunca utilize diretamente o link original do checkout.

Sempre utilize o link gerado pelo Trackup.

**\[IMAGEM RECOMENDADA\]**\
\
_(Editor da página mostrando botão configurado com link de checkout.)_

---

# Passo 9 — Crie um Link de Anúncio

Agora precisamos criar o link que será utilizado dentro da plataforma de tráfego.

Esse link é responsável por capturar:

- UTMs
- Click IDs
- Dados da campanha
- Origem do tráfego\

Fluxo:

```text
Anúncio
↓
Link de anúncio
↓
Página
```

Para criar:

- Vá em **Links**
- Clique em **Novo Link**
- Escolha **Link de Anúncio**
- Selecione a página criada anteriormente\

**\[IMAGEM RECOMENDADA\]**\
\
_(Tela criando link do tipo Anúncio.)_

---

# Passo 10 — Lance suas Campanhas

Agora toda infraestrutura está pronta.

Pegue o link de anúncio criado e utilize na sua campanha.

Exemplo:

```text
Meta Ads
↓
Usuário clica
↓
Trackup registra acesso
↓
Página carrega
↓
Usuário vai para checkout
↓
Conversão acontece
```

A partir daqui o sistema começa a registrar todos os eventos automaticamente.

**\[IMAGEM RECOMENDADA\]**\
\
_(Diagrama mostrando anúncio → link → página → checkout.)_

---

# Passo 11 — Valide suas Conversões

Antes de escalar campanhas, valide se toda estrutura está funcionando corretamente.

Checklist:

```text
✓ Domínio conectado
✓ Pixel ativo
✓ Plataforma de venda integrada
✓ Oferta criada
✓ Link de checkout funcionando
✓ Página publicada
✓ Link de anúncio criado
✓ Eventos sendo enviados
✓ Conversões sendo registradas
```

Verifique principalmente os módulos:

- Requisições
- Visitors
- Conversões\

Se tudo estiver aparecendo corretamente, sua operação está pronta.

# Fluxo completo da operação

```text
Campanha
↓
Link de anúncio
↓
Landing Page
↓
Botão de compra
↓
Link de checkout
↓
Checkout
↓
Webhook recebido
↓
Conversão registrada
↓
Evento enviado para pixel
↓
Dados aparecem nos relatórios
```

Essa é a arquitetura padrão utilizada pela maioria das operações dentro do Trackup.
