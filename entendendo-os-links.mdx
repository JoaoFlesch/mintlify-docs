# **Por que os links são tão importantes no Trackup**?

Dentro do ecossistema do Trackup, os Links são uma das partes mais importantes de toda infraestrutura.

Muito mais do que simplesmente redirecionar ou exibir páginas, os Links são responsáveis por iniciar o processo de rastreamento da jornada do usuário.

É nesse momento que o Trackup começa a capturar dados importantes, preservar parâmetros da origem do tráfego e conectar toda a navegação até a conversão final.

O Trackup oferece diferentes tipos de links para diferentes cenários operacionais.

Cada um possui uma função específica e dispara um tipo de evento.

Em outras palavras:

> Todo o tracking da sua operação começa no momento em que alguém acessa um Link Trackup.

# 1. Link Genérico

O tipo mais flexível de link dentro da plataforma.

Os Links Genéricos funcionam como links de rastreamento universais.

Eles podem ser utilizados em praticamente qualquer cenário onde você deseja apenas enviar tráfego preservando dados da jornada.

Ideal para:

- Redirecionamento dentro do seu Funil
- Links em bio
- Operações orgânicas

Eles não dependem de parâmetros específicos de plataformas de mídia.

Todo acesso  de um link genérico dispara um evento de page\_view

# 2. Link de Anúncio

Os Links de Anúncio foram desenvolvidos especificamente para campanhas de mídia paga.

Esse tipo de link identifica e processa parâmetros enviados pelas plataformas de anúncios e é personalizado para cada fonte de tráfego

Essas informações ajudam o Trackup a entender exatamente de onde aquele visitante veio e atribuir cada evento com o máximo de detalhes em uma futura conversão

Ideal para:

- Meta Ads
- Google Ads
- TikTok Ads
- Kwai Ads

Quando performance e atribuição importam, normalmente este será o tipo de link utilizado.

→ Entenda melhor como criar e o funcionamento de um **Link de Anúncio**

# 3. Checkout Link

O Checkout Link representa o último passo da jornada do usuário antes da conversão.

Esse tipo de link conecta o visitante à Oferta previamente cadastrada dentro do projeto.

Ele é responsável por garantir que todos os dados coletados durante a navegação continuem sendo preservados até o momento final da compra.

Importante.

Antes de criar um Checkout Link, você precisa cadastrar uma Oferta.

→ Entenda melhor como criar e o funcionamento de um **Link de Checkout**

# Preservação de parâmetros

Uma das funções mais importantes dos Links do Trackup é preservar informações importantes durante toda jornada do visitante.

Quando um usuário chega através de uma campanha, diversos parâmetros acompanham esse clique.

Exemplo.

```text
utm_source=facebook
utm_campaign=escala_junho
fbclid=123456789
```

Se esses parâmetros forem perdidos durante a navegação, a atribuição da conversão pode quebrar.

O Trackup garante que esses dados continuem existindo durante toda jornada, tendo em vista que tudo isso fica salvo em cada [requisição](/requisiocoes) e atribuído ao [visitante](/visitantes)

# O que é o Click ID do Trackup?

Sempre que alguém acessa um Link criado dentro da plataforma, o Trackup gera automaticamente um identificador único interno.

Chamamos isso de Click ID.

Esse identificador acompanha toda jornada do visitante.

Ele conecta todos os eventos relacionados àquele usuário.

Exemplo.

```text
Clique inicial

Page View

Navegação

Checkout

Conversão
```

Tudo fica associado ao mesmo identificador interno.

# Teste A/B integrado ⚖️

O módulo de Links também permite criar testes A/B.

Isso permite distribuir visitantes entre múltiplas páginas diferentes para identificar qual versão gera melhor performance.

Exemplo.

```text
50% → Landing A

50% → Landing B
```

Ou.

```text
70% → Landing A

30% → Landing B
```

O Trackup distribui automaticamente os visitantes com base na configuração definida.

Ideal para:

- Testar variações de Landing Pages ou VSLs
- Testar diferentes Gateways ou Checkouts
- Testar otimizações no funil
