O Builder é o editor visual do Trackup. Você arrasta componentes e blocos para o canvas, ajusta textos, imagens e estilos e publica no seu domínio. A página já sai com rastreamento.

Criar uma página no Builder

Em Páginas › Adicionar página, escolha a aba Builder, dê um nome e, se quiser, um caminho. Salve.

Na lista, abra o menu da página e clique em Editar no builder. O editor abre em uma nova aba.

Escolha um template pronto (pré-venda, VSL, captura e outros) ou comece com o canvas vazio.

O editor

ÁreaO que tem
Barra superiorNome da página, desfazer e refazer, visualização Desktop, Tablet e Mobile, Salvar e Publicar.
Painel lateralAbas Componentes, Blocos e Camadas.
CanvasA página como o visitante vai ver. Clique em um elemento para selecionar.
InspetorAbas Estilo e Config do elemento selecionado.

Atalhos de zoom: Ctrl 0, Ctrl 1 e Ctrl 2.

Componentes

Peças básicas: título, texto, botão, imagem, vídeo, ícone, badge, divisor, espaçador, container e grid. Arraste para o canvas ou para dentro de um container.

Blocos

Seções prontas, agrupadas por função: primeira dobra e VSL, benefícios, prova social, oferta e preço, perguntas frequentes, chamadas para ação, navegação e rodapé. Um bloco vira componentes comuns quando inserido, então você edita cada parte livremente.

Camadas

A árvore da página. Use para selecionar elementos difíceis de clicar no canvas, reordenar e ver o que está dentro de cada container.

Editar um elemento

Ajuste layout, espaçamento (margem e padding), tipografia, cores, fundo, borda, arredondamento, sombra, overflow e transformações. Cada campo tem um botão para voltar ao valor do tema.

Conteúdo e comportamento: texto, imagem (pela Biblioteca de imagens), URL do vídeo e o Evento de clique do botão, com o Destino.

Nos botões de compra, use como destino o link da sua oferta no Trackup. Um link direto para o checkout quebra a atribuição.

Responsivo

Alterne entre Desktop, Tablet e Mobile na barra superior para ver e ajustar a página em cada tamanho antes de publicar.

Salvar e publicar

  • Salvar guarda o rascunho. O link continua mostrando a versão publicada.
  • Publicar coloca a versão atual no ar. Salve antes de publicar.

Boas práticas

  • Comprima imagens antes de enviar. Páginas leves carregam rápido e convertem mais.
  • Revise a versão Mobile: a maior parte do tráfego pago vem do celular.
  • Para testar uma variação, Duplique a página e crie um teste A/B.
