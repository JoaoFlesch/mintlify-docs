# Três formas de criar páginas

O Builder foi projetado para se adaptar a diferentes tipos de usuários.

Seja você iniciante ou avançado, existem diferentes caminhos para criar sua página.

Você pode começar de três maneiras.

```text
1. Criar com auxílio de IA

2. Utilizar Templates Prontos

3. Construir Manualmente com Blocos
```

Cada método atende diferentes cenários operacionais.

# 1. Criar páginas com Inteligência Artificial 

A maneira mais rápida de colocar uma página no ar.

Basta descrever o que você deseja utilizando linguagem natural.

Nossa IA processa sua solicitação e gera automaticamente uma estrutura pronta para edição.

Isso reduz drasticamente o tempo necessário para iniciar uma nova campanha.

---

# 2. Utilizar Templates prontos 🎨

Se você prefere começar com uma base já estruturada, com modelos que já foram validados, o Builder oferece templates prontos desenvolvidos para diferentes tipos de operação.

Você pode escolher entre layouts já organizados e começar a personalizar imediatamente.

Exemplo de cenários.

- Landing pages
- Estruturas para VSL
- Pre-sell\

Os templates ajudam você a reduzir tempo de criação mantendo uma estrutura validada.

# 3. Construir do zero com Blocos 🧩

Se você deseja liberdade total, também é possível começar com uma página em branco.

Nesse modo, você constrói tudo manualmente utilizando nosso sistema de blocos e elementos pré prontos.

Você controla absolutamente toda estrutura da página.

Adicione componentes como:

- Títulos
- Botões
- Seções
- Imagens
- Vídeos
- Grids

Tudo com edição visual em tempo real.

# Total liberdade de personalização

O Builder foi criado para oferecer controle completo sobre o design da sua página.

Você pode alterar praticamente qualquer aspecto visual.

Exemplos.

- Espaçamento
- Tipografia
- Layout
- Responsividade
- Cores
- Botões
- Imagens
- Backgrounds
- Animações
- Estrutura das seções
- Organização dos elementos\

A ideia é simples.

# Tudo conectado ao restante da operação

Uma das maiores vantagens do Builder é estar completamente integrado ao restante do TrackUp.

Sua página não existe isoladamente.

Ela faz parte de toda operação.

Exemplo.

```text
Campanha
↓
Link do anúncio
↓
Página criada no Builder
↓
Visitante navega
↓
TrackUp coleta dados
↓
Usuário vai para checkout
↓
Conversão acontece
```

Toda infraestrutura funcionando dentro do mesmo ambiente.
