### Transforme acessos isolados em perfis completos de usuários reais.

Toda interação dentro do TrackUp começa com uma requisição.

Sempre que alguém acessa um link, visita uma página, inicia checkout ou realiza qualquer ação dentro da sua operação, o sistema registra aquela atividade individualmente.

Mas o verdadeiro poder do TrackUp acontece no próximo passo.

Cada requisição processada gera automaticamente um **Visitor**.

Esse Visitor representa a identidade persistente daquele usuário dentro do seu projeto.

Conforme o mesmo visitante continua navegando, o sistema conecta todas as novas interações ao mesmo perfil, acumulando informações progressivamente ao longo da jornada.

Em outras palavras:

> Quanto mais o usuário avança no funil, mais inteligente o TrackUp se torna sobre aquele visitante.

# Como funciona o sistema de Visitors?

Toda jornada começa com uma requisição individual.

Exemplo:

```text
```

```text
Usuário clicou em anúncio

↓

TrackUp registra requisição

↓

Sistema cria Visitor automaticamente
```

Se o mesmo usuário retornar posteriormente:

```text
```

```text
Novo acesso detectado

↓

TrackUp reconhece visitante

↓

Nova requisição é vinculada ao mesmo Visitor

↓

Perfil fica mais completo
```

Cada nova interação aumenta a quantidade de informações disponíveis.

# Toda requisição gera um Visitor

Sempre que uma nova visita passa pela infraestrutura do TrackUp, o sistema cria automaticamente um registro persistente daquele usuário.

Inicialmente esse visitante pode possuir poucas informações.

Exemplo:

```text
```

```text
IP

Dispositivo

Sistema operacional

Localização

Browser

UTMs

Click ID
```

Mas conforme o visitante continua navegando, novos dados começam a ser adicionados.

Exemplo:

```text
```

```text
Nome

Email

Telefone

Histórico de navegação

Eventos gerados

Conversões realizadas

Plataforma de pagamento utilizada
```

Cada etapa do funil adiciona novas camadas de informação.

---

# Construção progressiva do perfil 🧠

O TrackUp trabalha com enriquecimento progressivo de dados.

Isso significa que o perfil do visitante vai evoluindo conforme ele interage com sua operação.

Exemplo de evolução.

Primeiro acesso:

```text
```

```text
Visitante anônimo

Instagram

Android Device

utm_source = facebook
```

Após preencher formulário:

```text
```

```text
Nome identificado

Email capturado

Telefone capturado
```

Após checkout:

```text
```

```text
Start Checkout registrado

Plataforma de pagamento identificada
```

Após compra:

```text
```

```text
Conversão registrada

Valor da venda capturado

Método de pagamento identificado
```

O mesmo Visitor vai se tornando cada vez mais completo.

# Banco de dados central de visitantes

A página principal de Visitors funciona como uma base central de todos os usuários que passaram pela sua operação.

Diferente da página de Requisições, aqui não analisamos eventos isolados.

Aqui agrupamos tudo por indivíduo.

Cada linha representa uma pessoa.

Não uma visita.

---

# Identificação progressiva do visitante

Nem sempre o sistema consegue identificar o usuário imediatamente.

Quando o visitante ainda não forneceu dados pessoais, ele aparece como anônimo.

Exemplo:

```text
```

```text
96014e5d7fa83cb29...
```

Quando o sistema consegue capturar dados adicionais, o perfil é atualizado automaticamente.

Exemplo:

```text
```

```text
Gregory Anthoni
```

ou

```text
```

```text
everton@empresa.com.br
```

Isso acontece sem perder histórico anterior.

Ou seja:

O Visitor continua sendo o mesmo.

Apenas fica mais completo.

Ao clicar em qualquer visitante, o TrackUp abre uma visão completa daquela pessoa dentro do seu ecossistema.

Aqui toda jornada fica consolidada em um único lugar.

# Relação entre Requisições e Visitors

Esses dois módulos trabalham juntos.

### Requisições

Analisa eventos isolados.

Exemplo:

```text
```

```text
Uma visita específica

Um clique específico

Um evento específico
```

### Visitors

Agrupa toda jornada do mesmo usuário.

Exemplo:

```text
```

```text
Todas requisições do mesmo visitante

Todos eventos agrupados

Histórico consolidado

Conversões associadas
```

Ou seja:

```text
```

```text
Requisições mostram eventos

Visitors mostram pessoas
```

---

# Por que isso importa?

Muitas ferramentas mostram apenas cliques isolados.

O TrackUp vai além.

Ele constrói um histórico completo do usuário ao longo de toda jornada.

Isso significa:

- \
  mais contexto sobre cada visitante\
- \
  melhor atribuição\
- \
  visão completa do funil\
- \
  identificação de usuários mais engajados\
- \
  associação entre marketing e faturamento\

Você deixa de analisar tráfego.

Você começa a analisar pessoas.
