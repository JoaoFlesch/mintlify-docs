--- title: Upload HTML icon: file description: Hospede no Trackup uma página que você já tem em HTML. ---

Envie um arquivo .html ou um .zip com a página e os arquivos dela. O Trackup hospeda tudo no seu domínio e a página já sai rastreada.

Preparar o arquivo

  • Um único .html ou .htm, ou
  • um .zip com index.html na raiz e os arquivos usados por ela (CSS, JS, imagens, fontes).
  • Tamanho máximo: 5 MB.
pagina.zip ├── index.html ├── css/ │ └── style.css ├── js/ │ └── main.js └── img/ └── hero.webp

Use caminhos relativos (css/style.css, img/hero.webp). O Trackup reescreve as referências para servir os arquivos pelo CDN.

Enviar

Em Páginas › Adicionar página, escolha Upload HTML.

Informe o nome, o caminho (opcional), escolha o arquivo e clique em Enviar arquivo.

Copie o link na lista de páginas e abra no navegador.

Editar depois

Para ajustes pontuais, use Editar arquivos no menu da página. Veja Versões e arquivos.

Para trocar a página inteira, edite a página e envie um novo arquivo em Substituir HTML.

Substituir o HTML apaga todos os arquivos atuais, inclusive as alterações feitas no editor de arquivos.

Checklist

  • Os botões de compra apontam para o link da oferta.
  • Não há outro script de rastreamento ou pixel duplicando eventos que o Trackup já envia pelo servidor.
  • As imagens estão comprimidas.
