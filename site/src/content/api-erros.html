--- title: Erros icon: alert description: Códigos de status e formato das respostas de erro da API. ---

A API usa os códigos HTTP padrão. Respostas 2xx indicam sucesso, 4xx um problema na requisição e 5xx uma falha do Trackup.

Formato

A maioria dos erros traz error e message:

{ "error": "FORBIDDEN", "message": "Insufficient permissions" }

Erros de validação (422) trazem um objeto errors, com o caminho de cada campo e a primeira mensagem. _form indica um erro do objeto como um todo.

{ "errors": { "value": "Required" } }

Códigos

StatusSignificadoO que fazer
400Requisição incompleta, como projectId ausente em um endpoint de ingestão.Corrija a requisição.
401Header X-Api-Key ausente ou chave inválida.Confira a chave.
403Sem a permissão necessária, chave revogada ou expirada.Ajuste as permissões ou crie outra chave.
404Recurso não existe ou o projeto está fora do escopo da chave.Confira o ID e os projetos da chave.
409Conflito, como uma conversão com o mesmo transactionId e status.Não repita. O recurso já existe.
422Corpo ou parâmetros inválidos.Leia o objeto errors.
500Erro interno.Tente de novo com espera crescente.
502Falha em um serviço externo, como o câmbio ou a Meta.Tente de novo mais tarde.
