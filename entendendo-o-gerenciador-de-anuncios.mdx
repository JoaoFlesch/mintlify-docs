# Entendendo o Gerenciador de Anúncios 📊

### Centralize o controle das suas campanhas em um único lugar.

O Gerenciador de Anúncios do TrackUp foi criado para permitir que você acompanhe e controle campanhas de mídia paga sem precisar alternar entre múltiplas plataformas.

Em vez de depender exclusivamente do painel nativo de cada plataforma, o TrackUp conecta sua infraestrutura de anúncios diretamente ao restante da operação.

Isso permite centralizar dados, automatizar processos e criar uma visão unificada das campanhas em execução.

# Por que criamos o Gerenciador de Anúncios?

Quem trabalha com tráfego pago normalmente opera em múltiplos ambientes ao mesmo tempo.

Exemplo:

- Plataforma de anúncios
- Tracker
- Página de vendas
- Plataforma de checkout
- Ferramenta de analytics
- Pixel manager

Isso gera fragmentação de dados e reduz velocidade operacional.

O objetivo do TrackUp é unificar toda essa infraestrutura.

O Gerenciador de Anúncios faz parte dessa visão.

---

# O que o Gerenciador faz hoje?

Atualmente o módulo permite conectar contas de mídia e controlar campanhas diretamente dentro do TrackUp.

Hoje você consegue:

✓ Conectar contas de anúncios\
✓ Sincronizar campanhas automaticamente\
✓ Ativar campanhas\
✓ Pausar campanhas\
✓ Alterar orçamento\
✓ Visualizar dados operacionais\
✓ Centralizar métricas para dashboards futuros

Tudo isso sem sair da plataforma.

# Como funciona a sincronização?

Quando você conecta uma conta de anúncios ao TrackUp, o sistema começa a sincronizar automaticamente suas campanhas.

Essa sincronização permite que o TrackUp mantenha os dados atualizados em tempo real e possibilite ações diretas dentro da plataforma.

Exemplo:

```text
```

```text
Meta Ads → API do TrackUp → Sincronização → Campanhas disponíveis no painel
```

A sincronização acontece automaticamente após a integração inicial.

# Como isso se conecta com o restante do TrackUp?

O Gerenciador de Anúncios faz parte do ecossistema completo da plataforma.

Fluxo:

```text
```

```text
Campanha
↓
Usuário clica
↓
TrackUp captura parâmetros
↓
Usuário acessa página
↓
Conversão acontece
↓
Dados retornam para analytics
```

Isso permite centralizar toda operação em um único ambiente.
