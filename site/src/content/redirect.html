--- title: Redirect icon: external description: Passe o tráfego pelo Trackup e redirecione para uma página hospedada em outro lugar. ---

Uma página Redirect registra o acesso, aplica o filtro, dispara os eventos e manda o visitante para outra URL. Use quando a página precisa continuar em outro servidor, ou para criar uma oferta que leva ao checkout.

Criar

Em Páginas › Adicionar página , mantenha a aba Redirect. Para um checkout, use Ofertas › Adicionar oferta, que já é um redirecionamento.
CampoDescrição
NomeIdentificação no painel.
URL de redirecionamentoPara onde o visitante vai. O redirecionamento é temporário (302).
CaminhoEndereço no seu domínio, como /promo.

Salve, copie o link da página na lista e abra no navegador. Você deve cair na URL de destino.

Se o destino é uma landing page hospedada fora do Trackup, instale o script de rastreamento nela. Se o destino é uma página do Builder ou HTML do próprio Trackup, não precisa de script.

Parâmetros

Os parâmetros da URL do visitante, como utm_source e fbclid, são repassados ao destino. Se o mesmo parâmetro já existir fixo na URL de redirecionamento, vale o valor do visitante.

Qual status usar

Use 302, o padrão. Navegadores guardam em cache redirecionamentos 301 e 308, então uma troca de destino pode demorar a valer para quem já acessou.
