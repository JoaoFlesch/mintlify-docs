Muitos usuários já possuem páginas desenvolvidas externamente e precisam apenas de uma infraestrutura rápida, confiável e centralizada para publicar e gerenciar esses arquivos.

Foi exatamente para isso que criamos o módulo **Upload HTML**.

Com ele, você pode enviar suas próprias páginas, hospedar seus arquivos dentro do Trackup e gerenciar toda estrutura diretamente pela plataforma.

Além do upload, o Trackup oferece um ambiente interno de gerenciamento de arquivos com edição direta de código.

# Como funciona o Upload HTML?

Ao criar uma página utilizando esse método, você envia os arquivos responsáveis pela estrutura da página.

O Trackup processa automaticamente o conteúdo e publica a página dentro do seu projeto.

Você pode enviar dois formatos.

<Columns cols={2}>
  <Column>
    <Card title=" HTML ">
    </Card>
  </Column>
  <Column>
    <Card title="ZIP">
    </Card>
  </Column>
</Columns>

Após o envio, o Trackup organiza e publica automaticamente sua estrutura.

# Hospedagem integrada no próprio Trackup

Quando você envia sua página, os arquivos passam a ser hospedados diretamente dentro da infraestrutura do Trackup.

Isso significa que você não precisa depender de serviços externos para manter sua página online.

Todo o gerenciamento fica centralizado dentro do seu projeto.

Benefícios.

✓ Sem depender de hospedagens externas\
✓ Estrutura centralizada\
✓ Gerenciamento unificado\
✓ Deploy simplificado\
✓ Menos ferramentas externas na operação

Sua página passa a fazer parte do ecossistema completo do projeto.

---

# Gerenciador de arquivos integrado

Depois que sua página é enviada, todos os arquivos ficam disponíveis dentro do ambiente interno de gerenciamento.

Você poderá visualizar toda estrutura da página hospedada.

Exemplo.

```text
Minha Landing

├── index.html
├── style.css
├── script.js
├── assets/
│      ├── logo.png
│      ├── banner.webp
│      └── icon.svg
│
└── fonts/
```

Todo arquivo fica acessível para gerenciamento posterior.

# Editor de código integrado

Uma das grandes vantagens do Upload HTML é o editor interno do Trackup.

Você pode abrir qualquer arquivo hospedado e editar diretamente pela plataforma.

Sem precisar baixar arquivos novamente.

Sem precisar utilizar software externo.

O editor funciona de forma semelhante a um ambiente moderno de desenvolvimento.

Você pode editar arquivos como.

- HTML
- CSS
- JavaScript
- JSON
- Arquivos de configuração
- Assets da página

Tudo em tempo real.
