Os Pixels são responsáveis por conectar o Trackup às plataformas de mídia utilizadas na sua operação.

Sempre que um evento acontece dentro da jornada do usuário, o Trackup pode enviar essas informações diretamente para a plataforma correspondente.

# Adicionando um novo Pixel

Para conectar uma nova plataforma basta clicar em:

```text
+ Adicionar Pixel
```

Ao iniciar a configuração, o Trackup abre um painel lateral com os dados necessários para integração.

O formulário se adapta automaticamente dependendo da plataforma escolhida.

Isso significa que cada integração exibe apenas os campos realmente necessários.

O processo fica muito mais simples.

# Plataformas suportadas

 O Trackup suporta integração com múltiplos pixels.\
Todas funcionam dentro da mesma lógica central.\
Cada uma possui campos específicos de autenticação.

## Meta

Integração com o ecossistema da Meta para envio de eventos através da API de Conversões.

```text
Pixel ID
Access Token
Test Event Code (opcional)
```

## Google

Integração com o ecossistema da Google para envio de eventos através da API de Conversões.

```text
Conversion ID
Moeda padrão
Valor padrão
```

## Kwai

Integração com o ecossistema da Kwai para envio de eventos através da API de Conversões.

```text
Pixel ID
Access Token
Test Event Code
```

# Integração total com Acionadores

Pixels trabalham diretamente conectados ao módulo de [Acionadores](/acionadores).

Fluxo:

```text
Evento acontece
↓
Acionador valida condições
↓
Ação é executada
↓
Pixel envia evento para plataforma
```

Sem [Acionadores](/acionadores), os Pixels ficam sem função.

Com [Acionadores](/acionadores), eles começam a trabalhar.

Esses dois módulos funcionam juntos.

---

# Server-side por padrão

Sempre que possível, o Trackup prioriza envio server-side.

Isso significa que os eventos são enviados diretamente pelos nossos servidores.

Benefícios:

- maior confiabilidade
- menos bloqueios por adblockers
- melhor atribuição
- maior taxa de entrega de eventos
- dados mais consistentes

A plataforma foi construída priorizando esse modelo.
