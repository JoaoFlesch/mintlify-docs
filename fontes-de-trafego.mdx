# Fontes de Tráfego 🚦

### Configure como suas plataformas de anúncios enviam dados para o TrackUp.

Todo o ecossistema do TrackUp depende de uma coisa fundamental:

Receber informações corretas sobre a origem de cada visitante.

Sempre que alguém clica em um anúncio, a plataforma de mídia envia parâmetros na URL contendo informações sobre campanha, conjunto de anúncios, criativo, palavra-chave e outros identificadores importantes.

O módulo de **Fontes de Tráfego** é responsável por definir exatamente quais parâmetros serão enviados e como o TrackUp irá interpretar essas informações.

Em outras palavras:

> Esta página define o idioma que seus links irão falar com as plataformas de anúncios.

Se essa configuração estiver errada, toda sua atribuição fica comprometida.

# O papel das Fontes de Tráfego dentro do TrackUp

Sempre que alguém acessa sua operação através de mídia paga, o link normalmente carrega parâmetros invisíveis na URL.

Exemplo:

```text
utm_source=facebook
utm_campaign=campanha_teste
utm_medium=conjunto_01
utm_content=criativo_video_03
fbclid=ABCD123456
```

Esses parâmetros são extremamente importantes.

Eles permitem que o TrackUp descubra:

```text
Qual campanha gerou o clique

Qual conjunto de anúncios originou a visita

Qual anúncio foi exibido

Qual criativo trouxe o usuário

Qual palavra-chave gerou a visita

Qual plataforma originou o tráfego
```

Sem isso, o sistema fica sem contexto.

# Adicionando uma nova Fonte

Para configurar uma nova plataforma basta clicar em:

```text
+ Adicionar Fonte
```

Ao abrir o editor, o TrackUp exibe um construtor dinâmico de parâmetros.

O comportamento da interface muda automaticamente dependendo da plataforma selecionada.

Cada mídia possui sua própria forma de construir URLs.

O TrackUp já entende essas diferenças e adapta tudo automaticamente.

---

# O que exatamente estamos configurando?

Aqui você define quais informações a plataforma irá enviar para o TrackUp sempre que um clique acontecer.

Os parâmetros mais comuns são:

```text
utm_source

utm_medium

utm_campaign

utm_content

utm_term

click_id
```

Exemplo prático:

```text
Usuário clica no anúncio

↓

Plataforma adiciona parâmetros na URL

↓

TrackUp recebe esses dados

↓

Sistema associa clique à campanha correta
```

Esses parâmetros serão utilizados posteriormente nos módulos de:

- Requisições
- Visitors
- Conversões
- Relatórios
- Atribuição de campanhas

---

# Templates automáticos por plataforma 🤖

Cada plataforma possui seu próprio padrão interno de parâmetros dinâmicos.

Para facilitar o processo, o TrackUp já pré-configura automaticamente os valores recomendados.

Você não precisa montar manualmente.

---

# Meta Ads

Ao selecionar Meta, o TrackUp utiliza automaticamente as macros oficiais do ecossistema da Meta.

Exemplo de parâmetros utilizados:

```text
utm_source=facebook

utm_medium={{adset.name}}|{{adset.id}}

utm_campaign={{campaign.name}}|{{campaign.id}}

utm_content={{ad.name}}|{{ad.id}}
```

Essas variáveis são interpretadas automaticamente pelo Gerenciador de Anúncios da Meta.

Ao final, o sistema gera a URL pronta para copiar e utilizar nas campanhas.

# Google Ads

O Google utiliza uma sintaxe diferente para seus parâmetros dinâmicos.

O TrackUp adapta automaticamente a estrutura para o padrão exigido pelo Google Ads.

Exemplo:

```text
utm_source=google

utm_medium=cpc

utm_campaign={campaignid}

utm_content={creative}

utm_term={keyword}
```

O Google utiliza tokens com chaves simples.

Toda sintaxe é montada automaticamente pelo sistema.

Nenhuma configuração manual complexa é necessária.

---

**\[IMAGEM RECOMENDADA\]**

_(Utilizar print mostrando formulário Google com tokens {campaignid}, {creative} e {keyword}.)_

---

# Kwai Ads

A plataforma Kwai utiliza uma nomenclatura própria para seus parâmetros dinâmicos.

Ao selecionar Kwai, o sistema altera automaticamente os placeholders para o padrão correto.

Exemplo:

```text
utm_source=kwai

utm_campaign=__CMPN__

utm_medium=__ADSET__

utm_content=__AD__
```

O TrackUp entende o formato exclusivo da plataforma e gera tudo automaticamente.

Você apenas copia e utiliza na campanha.

---

**\[IMAGEM RECOMENDADA\]**

_(Utilizar print mostrando formulário Kwai com placeholders **CMPN**, **ADSET** e **AD**.)_

# TikTok Ads

Assim como as demais plataformas, o TikTok possui seus próprios parâmetros internos.

Ao selecionar TikTok, o sistema prepara automaticamente o modelo recomendado para rastreamento.

Exemplo:

```text
utm_source=tiktok

utm_campaign={{campaign_name}}

utm_medium={{adgroup_name}}

utm_content={{ad_name}}
```

Toda lógica segue exatamente o mesmo princípio das demais integrações.

O objetivo continua sendo o mesmo:

Garantir que o TrackUp receba dados corretos de atribuição.

# Crie parâmetros personalizados

Além dos templates automáticos, você também pode adicionar parâmetros completamente personalizados.

Isso permite adaptar o TrackUp para operações específicas.

Exemplo:

```text
affiliate_id

offer_id

creator_name

partner_code

tracking_id
```

Esses parâmetros personalizados também ficam disponíveis em todo ecossistema da plataforma.

Podendo ser utilizados em:

- Links
- Acionadores
- Logs
- Conversões
- Relatórios futuros

Isso torna o sistema extremamente flexível.

---

# Geração automática da URL final ⚡

Conforme você configura os parâmetros, o TrackUp gera automaticamente a string final pronta para uso.

Exemplo:

```text
utm_source=facebook&utm_campaign={{campaign.name}}&utm_medium={{adset.name}}&utm_content={{ad.name}}
```

Você simplesmente copia essa estrutura e cola dentro da plataforma de anúncios.

Sem precisar montar manualmente.

Sem risco de erro de sintaxe.

# Por que essa configuração é tão importante?

Se a Fonte de Tráfego estiver mal configurada, o restante do sistema perde inteligência.

Problemas comuns:

```text
Campanha não identificada

Criativo não identificado

Conversão sem atribuição

Relatórios incompletos

Pixel sem contexto correto

Falha no tracking financeiro
```

Exemplo:

```text
Venda registrada normalmente

↓

Mas utm_campaign não chegou

↓

TrackUp não consegue identificar qual campanha vendeu
```

Resultado:

```text
Seu relatório fica cego
```
