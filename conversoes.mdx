Sempre que uma integração envia uma confirmação de pagamento para o TrackUp, todos os dados relacionados àquela conversão são processados e armazenados. 

Isso inclui informações da transação, origem do tráfego, parâmetros de marketing, identificadores de rastreamento, dados da campanha e toda a jornada de atribuição associada à venda.

Esse módulo funciona como a camada final do tracking, permitindo entender exatamente qual caminho levou um visitante até a conversão.

No módulo de Conversões você encontra uma lista com todas as vendas registradas dentro do projeto.

Cada linha representa uma conversão recebida através de alguma integração.

Ao expandir uma conversão, informações adicionais ficam disponíveis.\

# Dados da venda

Esta seção contém informações financeiras da transação.

Campos disponíveis:

| Campo | Descrição |
| :-- | :-- |
| ID | Identificador interno da conversão |
| ID da transação | ID retornado pela plataforma de venda |
| Valor original | Valor bruto recebido |
| Data | Momento em que a conversão foi registrada |
| Plataforma | Plataforma responsável pela venda |
| Moeda | Moeda utilizada |
| Método de pagamento | Forma de pagamento utilizada |
| Câmbio utilizado | Conversão de moeda aplicada |
| Status | Estado atual da transação |

Exemplo:

```text
Plataforma: Hotmart
Valor: R$1350.50
Pagamento: Cartão de Crédito
Status: Pago
```

# Atribuição

A seção de atribuição é responsável por conectar a venda ao clique original que gerou a conversão.

Se a atribuição for bem sucedida, o sistema identifica exatamente qual visitante realizou a compra.

Dados disponíveis:

| Campo | Descrição |
| :-- | :-- |
| IP | IP identificado no momento da venda |
| Link ID | Link utilizado pelo visitante |
| Visitor ID | Identificador único do visitante |
| Request ID | Identificador da requisição original |
| URL ID | Página associada ao acesso |

---

# O que acontece durante a atribuição

Quando uma venda chega ao TrackUp, o sistema procura identificar:

```text
Qual anúncio gerou o clique?
↓
Qual visitante realizou o acesso?
↓
Qual página foi visitada?
↓
Qual checkout foi acessado?
↓
Qual venda pertence àquele usuário?
```

Se essa correlação for encontrada, a conversão será atribuída corretamente.

---

# Aviso de Click ID ausente

Em alguns casos você verá o seguinte alerta:

```text
Click ID ausente nesta conversão
```

Isso significa que a plataforma de venda não conseguiu enviar o identificador de rastreamento necessário para relacionar a venda ao clique original.

Normalmente isso acontece por problemas de configuração.

Exemplo:

```text
Esta conversão não registrou um Click ID
```

# Marketing & UTMs

Esta seção mostra os parâmetros capturados durante a jornada do visitante.

Campos disponíveis:

| Campo | Descrição |
| :-- | :-- |
| Fonte de tráfego | Plataforma que originou o acesso |
| UTM Source | Origem da campanha |
| UTM Medium | Tipo de tráfego |
| UTM Campaign | Nome da campanha |
| UTM Term | Palavra chave ou segmentação |
| UTM Content | Criativo utilizado |
| Click ID | Identificador do clique |

Exemplo:

```text
utm_source=meta
utm_campaign=escala_junho
utm_medium=cpc
fbclid=xxxxxxxx
click_id=track_93847
```

Esses dados são fundamentais para atribuição correta.

# Sub parâmetros

Sub parâmetros permitem enviar dados adicionais durante o tracking.

Campos suportados:

```text
sub1
sub2
sub3
sub4
sub5
sub6
sub7
sub8
```

Esses parâmetros podem ser usados para:

- Segmentação
- IDs internos
- Identificação de afiliados
- Tracking personalizado\

Exemplo:

```text
sub1=affiliate_22
sub2=campaign_7
sub3=creative_b
```

# Dados dos anúncios

Se a origem do tráfego for identificada, o sistema também associa informações da campanha.

Campos possíveis:

| Campo | Descrição |
| :-- | :-- |
| Plataforma de anúncio | Plataforma utilizada |
| Conta de anúncio | Conta conectada |
| Campanha ID | ID da campanha |
| Conjunto ID | ID do adset |
| Anúncio ID | ID do anúncio |

Exemplo:

```text
Plataforma: Meta Ads
Campanha ID: 23847298374
Adset ID: 23847298375
Ad ID: 23847298376
```
