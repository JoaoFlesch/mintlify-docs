# Plataformas de Venda 🛒

### Conecte seus checkouts ao TrackUp e receba dados de conversão automaticamente.

Todo o ecossistema do TrackUp foi construído para acompanhar a jornada do usuário desde o primeiro clique até o momento final da venda.

Mas existe uma etapa fundamental nesse processo.

Quando uma compra acontece, o TrackUp precisa ser avisado.

É exatamente aqui que entram as **Plataformas de Venda**.

Este módulo permite integrar seus checkouts, gateways e plataformas de pagamento para que o sistema receba automaticamente os dados financeiros de cada compra realizada.

Em outras palavras:

> Quando o cliente compra, sua plataforma precisa avisar o TrackUp imediatamente.

Sem isso, nenhuma conversão pode ser atribuída corretamente.

# O papel das Plataformas de Venda dentro do TrackUp

Durante toda jornada do visitante, o TrackUp coleta informações sobre o comportamento do usuário.

Exemplo:

```text
Clique no anúncio

↓

Landing page acessada

↓

Visitor criado

↓

Eventos processados

↓

Checkout iniciado
```

Mas quando a venda acontece, o sistema precisa receber os dados financeiros para fechar o ciclo.

Fluxo final:

```text
Pagamento aprovado

↓

Plataforma envia webhook

↓

TrackUp recebe dados da venda

↓

Conversão é registrada

↓

Campanha recebe atribuição
```

Sem essa integração, o sistema não consegue registrar o faturamento.

# O que é o Webhook?

O Webhook é o mecanismo responsável por avisar o TrackUp quando uma venda acontece.

Funciona assim:

Quando o pagamento é aprovado dentro da plataforma de venda, ela envia uma notificação automática para o TrackUp contendo os dados da transação.

Exemplo:

```text
Cliente realiza compra

↓

Pagamento aprovado

↓

Plataforma envia webhook

↓

TrackUp recebe dados financeiros

↓

Conversão é registrada
```

Sem esse processo, o sistema nunca saberá que uma venda aconteceu.

---

# Cada integração gera uma URL exclusiva 🔗

Sempre que você adiciona uma nova plataforma, o TrackUp gera automaticamente uma URL exclusiva de Webhook.

Exemplo:

```text
https://trackup.me/api/webhook/abc123xyz
```

Essa URL deverá ser copiada e adicionada dentro da plataforma de venda correspondente.

Exemplo:

```text
Hotmart → Área de Webhooks

Kiwify → Configuração de integração

Braip → Notificações automáticas

PerfectPay → Configuração de API
```

A partir desse momento, toda venda passa a ser enviada automaticamente para o TrackUp.

# Configurando parâmetros do checkout ⚙️

Antes da venda acontecer, o usuário precisa chegar até o checkout levando consigo todas as informações de atribuição coletadas anteriormente.

É nesta etapa que definimos quais parâmetros acompanharão o visitante durante o redirecionamento.

Exemplo de parâmetros normalmente enviados:

```text
sck

utm_source

utm_medium

utm_campaign

utm_content

click_id
```

Esses parâmetros são anexados automaticamente ao checkout.

---

# Como funciona o mapeamento de parâmetros?

Cada plataforma possui sua própria estrutura de URL.

O TrackUp permite mapear quais valores serão enviados dinamicamente durante o checkout.

Exemplo:

```text
sck={request.id}

utm_source={request.utmSource}

utm_medium={request.utmMedium}

utm_campaign={request.utmCampaign}
```

Significado:

```text
request.id → identificador único do visitante

request.utmSource → origem do tráfego

request.utmCampaign → campanha responsável pelo clique
```

Esses valores serão preenchidos automaticamente em tempo real.

# Adicione parâmetros personalizados

Algumas plataformas trabalham com campos proprietários ou parâmetros adicionais.

Por isso o sistema permite criar parâmetros completamente personalizados.

Exemplo:

```text
affiliate_id

offer_code

checkout_id

transaction_source

partner_reference
```

Você pode adicionar quantos parâmetros forem necessários para sua operação.

# Por que essa integração é tão importante?

Sem conectar sua plataforma de vendas, o TrackUp perde a etapa final do funil.

Problemas comuns quando não existe integração:

```text
Venda aconteceu

↓

TrackUp não recebeu webhook

↓

Conversão não foi registrada

↓

Pixel de Purchase não foi enviado

↓

Campanha não aprende com a venda

↓

Relatórios ficam incompletos
```

Ou seja:

Seu dinheiro entrou.

Mas sua inteligência de dados morreu no checkout.
