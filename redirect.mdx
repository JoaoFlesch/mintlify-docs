### Utilize páginas externas dentro da sua operação sem precisar migrar sua infraestrutura.

Nem toda operação precisa hospedar páginas diretamente dentro do TrackUp.

Muitas vezes você já possui landing pages, VSLs ou estruturas hospedadas em outros serviços e simplesmente quer continuar utilizando essas páginas sem alterar sua infraestrutura atual.

Para isso existe o modo **Redirect**.

Com ele, você cadastra uma URL externa e integra essa página ao restante da sua operação dentro do projeto.

Em outras palavras:

> O Redirect permite conectar páginas externas ao ecossistema do TrackUp.

# Quando utilizar Redirect?

O modo Redirect é ideal quando sua página já está publicada em outro lugar e você não deseja reconstruí-la dentro do TrackUp.

Exemplos comuns.

Você possui uma landing page hospedada em:

- VPS própria
- WordPress
- Cloudflare Pages
- Vercel
- Hospedagem tradicional
- Qualquer outra infraestrutura externa

Em vez de migrar essa página, você simplesmente conecta ela ao seu projeto.

# Como funciona o Redirect?

Ao criar uma página no modo Redirect, você informa uma URL externa já existente.

Essa página passa a fazer parte da sua estrutura dentro do projeto atual.

Fluxo:

```text
```

```text
Usuário acessa sua operação
↓
TrackUp processa o fluxo
↓
Visitante é enviado para sua URL cadastrada
↓
Navegação continua normalmente
```

Você continua utilizando sua infraestrutura atual, mas mantém a operação centralizada.

---

# Como criar uma página Redirect

Criar uma página via Redirect leva apenas alguns segundos.

Você precisará informar duas informações.

### Nome

Utilize um nome fácil de identificar dentro do projeto.

Exemplos:

- \
  Landing Principal\
- \
  VSL Principal\
- \
  Página de Captura\
- \
  Pré Checkout\

---

### URL de Redirecionamento

Aqui você informará a URL da página externa que receberá o visitante.

Exemplo:

```text
```

```text
https://meusite.com
```

Após salvar, a página ficará disponível dentro do seu projeto.

# Exemplo prático

Imagine que você já possui uma landing page hospedada externamente.

Exemplo:

```text
```

```text
https://produto-exemplo.com
```

Em vez de recriar essa página no Builder, você simplesmente cadastra essa URL no modo Redirect.

Fluxo:

```text
```

```text
Campanha
↓
Link do TrackUp
↓
Página cadastrada em Redirect
↓
Usuário acessa página externa
↓
Continuação da jornada
```

Isso permite manter sua estrutura atual sem refazer páginas.

---

# Quando NÃO utilizar Redirect

Embora seja extremamente útil, Redirect não é ideal para todos cenários.

Evite utilizar quando você deseja:

- \
  Criar páginas diretamente dentro do TrackUp\
- \
  Editar visualmente a página\
- \
  Hospedar arquivos internamente\
- \
  Utilizar templates do Builder\
- \
  Construir páginas novas do zero\

Nesses casos, outras opções serão mais adequadas.

---

# Redirect vs outras opções

Cada tipo de página atende necessidades diferentes.

| Se você quer… | Utilize |
| :-- | :-- |
| Usar uma página já hospedada externamente | Redirect |
| Criar páginas visualmente dentro do TrackUp | Builder |
| Publicar arquivos próprios | Upload HTML |
| Replicar uma página existente | Clonar URL |

Escolher o método correto ajuda a manter sua operação organizada.

# Boas práticas

Algumas recomendações importantes.

### Utilize nomes descritivos

Evite:

```text
```

```text
Página 1
Landing nova
teste
```

Prefira:

```text
```

```text
Landing Principal
VSL Produto Financeiro
Página Pré Checkout
Página Captura Webinar
```

---

### Sempre valide a URL antes de salvar

Certifique-se que a URL cadastrada está funcionando normalmente.

---

### Organize páginas por função

Exemplo:

```text
```

```text
Landing Principal
Página Captura
Página Pré Checkout
Página VSL
```

Isso facilita organização futura.

---

### Mantenha páginas relacionadas dentro do projeto correto

Evite misturar operações diferentes no mesmo projeto.

---

# Vantagem do Redirect

O maior benefício do Redirect é permitir que você mantenha sua infraestrutura atual sem precisar migrar páginas para outra plataforma.

Você continua usando o que já funciona enquanto centraliza sua operação dentro do TrackUp.
