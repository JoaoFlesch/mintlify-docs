### Descubra exatamente de onde cada venda veio.

Todo o ecossistema do TrackUp existe para responder uma pergunta fundamental:

> Qual campanha realmente está gerando dinheiro?

Capturar cliques, preservar parâmetros, rastrear visitantes, registrar eventos e disparar pixels são etapas fundamentais da operação.

Mas o verdadeiro objetivo sempre será o mesmo.

Medir resultados financeiros.

O módulo de **Conversões** conecta o momento final da jornada com toda a inteligência coletada anteriormente.

Aqui você consegue identificar exatamente qual visitante, qual anúncio, qual campanha e qual estrutura geraram receita para sua operação.

Em outras palavras:

> O TrackUp conecta dinheiro real com a origem exata que gerou essa venda.

# O que são Conversões?

Sempre que uma venda acontece em uma plataforma integrada ao TrackUp, o sistema recebe automaticamente os dados daquela transação.

Normalmente isso acontece através das integrações com plataformas de venda e gateways de pagamento.

Exemplos:

```text
```

```text
PerfectPay

Kiwify

Hotmart

Kirvano

Upag
```

Assim que o pagamento é processado, o TrackUp recebe as informações da venda e inicia o processo de atribuição.

---

# O papel das Conversões dentro do ecossistema TrackUp

Durante toda jornada do usuário, o sistema vai coletando dados progressivamente.

Exemplo:

```text
```

```text
Clique no anúncio

↓

Landing Page acessada

↓

Visitor criado

↓

Eventos disparados

↓

Checkout iniciado

↓

Pagamento realizado

↓

TrackUp recebe conversão
```

No momento em que a venda acontece, o sistema conecta essa receita a toda jornada anterior daquele usuário.

Nada fica isolado.

# Cada venda é automaticamente atribuída

Quando uma conversão chega ao TrackUp, o sistema não apenas registra o pagamento.

Ele tenta reconstruir toda origem daquela venda.

O objetivo é responder:

```text
```

```text
Quem comprou?

Qual anúncio trouxe essa pessoa?

Qual campanha originou a venda?

Qual criativo gerou a conversão?
```

Toda venda passa por um processo automático de atribuição.

Fluxo:

```text
```

```text
Webhook recebido
↓

Sistema identifica Visitor

↓

TrackUp localiza Click ID

↓

UTMs são associadas

↓

Campanha é identificada

↓

Venda recebe atribuição completa
```

Ao clicar em qualquer conversão registrada, o TrackUp exibe uma análise completa daquela venda.

Essa visão detalhada mostra exatamente de onde aquele dinheiro veio.

# Diagnóstico inteligente de problemas ⚠️

Nem toda conversão chega com dados perfeitos.

Quando existe algum problema de rastreamento, o TrackUp detecta automaticamente inconsistências.

O sistema alerta quando informações críticas estão ausentes.

Exemplo comum:

```text
```

```text
Venda chegou

↓

Pagamento confirmado

↓

Mas Click ID não foi encontrado
```

Nesse cenário a venda existe.

Mas a atribuição fica comprometida.

---

# Alertas automáticos

Quando o sistema detecta problemas na estrutura de tracking, um alerta visual é exibido.

Exemplo:

```text
```

```text
⚠️ Click ID ausente nesta conversão
```

Mensagem:

```text
```

```text
Esta conversão não registrou um Click ID.

Isso normalmente indica problemas na configuração dos Links, parâmetros ou integração com a plataforma de vendas.
```

Esse alerta ajuda a identificar falhas rapidamente.

# Por que o Click ID é tão importante?

O Click ID funciona como o elo entre o clique inicial e a venda final.

Exemplo:

```text
```

```text
Facebook gera clique

↓

Usuário acessa Link TrackUp

↓

TrackUp preserva Click ID

↓

Usuário compra

↓

Conversão é enviada de volta para Meta
```

Sem o Click ID:

```text
```

```text
A venda existe

Mas a plataforma de anúncios não consegue identificar qual clique gerou a conversão
```

Resultado:

```text
```

```text
Campanhas perdem qualidade de otimização
```
