### Configure os destinos de conversão da sua operação.

Dentro do ecossistema do TrackUp, uma Oferta representa o destino final onde sua conversão acontece.

Na prática, uma Oferta funciona como o checkout responsável por receber o visitante após toda a jornada de navegação.

Essa configuração é fundamental porque permite que o TrackUp conecte corretamente o clique inicial do usuário com a conversão final.

Em outras palavras:

> A Oferta é o ponto onde sua venda acontece.

# Onde as Ofertas entram no fluxo?

Dentro do TrackUp, toda operação segue uma sequência lógica.

```text
```

```text
Campanha
↓
Link de anúncio
↓
Landing Page
↓
Link de checkout
↓
Oferta
↓
Conversão
↓
Evento disparado
```

A Oferta representa exatamente o destino final dessa jornada.

É nela que a venda acontece.

# O que é uma Oferta?

Uma Oferta é o cadastro do checkout ou página final responsável por receber a conversão do usuário.

Quando você cadastra uma Oferta, você está dizendo ao TrackUp:

> “Quando eu enviar o visitante para finalizar a compra, este é o destino final da conversão.”

Cada Oferta fica vinculada ao Projeto atual.

---

### Exemplo

Se você vende um produto digital utilizando uma plataforma externa.

```text
```

```text
Produto → Curso Premium

Oferta cadastrada → Checkout oficial do produto
```

Ou:

```text
```

```text
Produto → Suplemento

Oferta cadastrada → Página final de pagamento
```

# Como criar uma Oferta

Criar uma Oferta leva apenas alguns segundos.

Você precisará informar duas informações.

### Nome

Utilize um nome que identifique facilmente o checkout.

Exemplo:

- \
  Checkout Principal\
- \
  Oferta Frontend\
- \
  Upsell Principal\
- \
  Checkout Nutra V1\

### URL de Redirecionamento

Aqui você deve informar a URL final do checkout responsável por receber o visitante.

Exemplo:

```text
```

```text
https://checkout.exemplo.com
```

Após salvar, essa Oferta ficará disponível para ser utilizada em Links de Checkout.

# Por que cadastrar uma Oferta primeiro?

Dentro do TrackUp, os Links de Checkout dependem de uma Oferta previamente cadastrada.

Isso acontece porque o sistema precisa saber para onde enviar o visitante no momento final da jornada.

Fluxo:

```text
```

```text
Primeiro você cria a Oferta
↓
Depois cria o Link de Checkout
↓
O Link utilizará essa Oferta como destino final
```

Sem uma Oferta cadastrada, não será possível criar corretamente o fluxo de pagamento.

---

# Como isso funciona na prática

Imagine a seguinte operação.

Você possui uma campanha no Meta Ads.

O usuário clica no anúncio.

Ele passa pelo seu funil.

Quando estiver pronto para comprar, você enviará esse usuário para um Link de Checkout criado no TrackUp.

Esse Link utilizará uma Oferta previamente cadastrada.

Exemplo:

```text
Meta Ads
↓
Landing Page
↓
Botão Comprar
↓
Link de Checkout do TrackUp
↓
Oferta cadastrada
↓
Usuário vai para checkout
↓
Conversão acontece
```

Toda essa estrutura ajuda o sistema a preservar os dados da jornada corretamente.

# Boas práticas ao criar Ofertas

Recomendamos seguir algumas práticas simples.

### Utilize nomes descritivos

Evite:

```text
```

```text
Oferta 1
Oferta teste
checkout novo
```

Prefira:

```text
```

```text
Checkout Principal
Frontend Financeiro
Upsell Nutra V2
PerfectPay Oferta Principal
```

---

### Crie ofertas separadas para operações diferentes

Não reutilize o mesmo checkout em operações completamente diferentes.

Separar facilita organização.

---

### Sempre valide a URL final

Certifique-se que a URL cadastrada está funcionando corretamente antes de utilizar nos Links de Checkout.

---

### Organize por funil

Se sua operação possui múltiplas etapas.

Exemplo:

```text
```

```text
Oferta 1 → Frontend

Oferta 2 → Upsell

Oferta 3 → Order Bump
```

---

# Exemplo de estrutura recomendada

```text
```

```text
Projeto → Produto Financeiro

Ofertas cadastradas

• Checkout Principal
• Upsell VSL
• Oferta Recorrente
• Oferta Order Bump
```

Organizar corretamente facilita muito a escalabilidade futura.

---

# Erros comuns

Evite os seguintes erros.

---

### Cadastrar URL incorreta

Uma URL errada interrompe toda jornada do usuário.

---

### Criar nomes genéricos demais

Isso dificulta organização quando sua operação cresce.

---

### Criar Links de Checkout sem planejar a Oferta antes

Sempre cadastre primeiro o destino final.
