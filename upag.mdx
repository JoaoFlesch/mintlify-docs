# \[Nome da Plataforma\] Integration

### Aprenda a conectar sua conta da \[Plataforma\] ao TrackUp e registrar conversões automaticamente.

Integrar a **\[Nome da Plataforma\]** ao TrackUp permite que nossa infraestrutura receba automaticamente os dados financeiros das vendas realizadas no seu checkout.

Sempre que uma compra for aprovada, a plataforma enviará uma notificação automática para o TrackUp, permitindo registrar a conversão, atribuir a venda corretamente e alimentar seus pixels de anúncios.

Em outras palavras:

> Quando uma venda acontece, o TrackUp precisa receber essa informação em tempo real.

# O que essa integração permite?

Ao conectar sua conta da **\[Plataforma\]**, o TrackUp poderá:

- registrar vendas automaticamente
- identificar origem da conversão
- relacionar a venda ao visitante correto
- identificar campanha responsável pela venda
- enviar eventos de conversão para plataformas de mídia
- alimentar relatórios financeiros do projeto

Fluxo:

```text
```

```text
Usuário acessa página

↓

Vai para checkout

↓

Compra é aprovada

↓

[Plataforma] envia webhook

↓

TrackUp recebe venda

↓

Conversão é registrada
```

# Passo 2 — Configurar parâmetros de tracking

Agora você precisará configurar quais informações serão enviadas junto com o checkout.

Esses parâmetros permitem manter toda atribuição da campanha durante a jornada do usuário.

Exemplo:

```text
```

```text
sck={request.id}

utm_source={request.utmSource}

utm_medium={request.utmMedium}

utm_campaign={request.utmCampaign}

utm_content={request.utmContent}
```

Esses valores serão preenchidos automaticamente pelo TrackUp.

---

### O que cada parâmetro significa?

| Parâmetro | Função |
| :-- | :-- |
| sck | Identificador único da sessão |
| utm\_source | Origem do tráfego |
| utm\_medium | Conjunto ou mídia |
| utm\_campaign | Nome da campanha |
| utm\_content | Criativo responsável |

# Passo 3 — Salvar a integração

Depois de configurar os parâmetros clique em:

```text
```

```text

```

Após salvar, o TrackUp irá gerar automaticamente uma URL exclusiva de Webhook.

Exemplo:

```text
```

```text
https://trackup.me/api/webhook/xxxxxxxxxxxx
```

Essa URL será utilizada no próximo passo.

# Problemas comuns

### Conversão não apareceu

Possíveis causas:

- \
  webhook não configurado\
- \
  URL copiada incorretamente\
- \
  plataforma não enviou notificação\
- \
  integração salva incorretamente\

---

### Conversão apareceu sem campanha

Possíveis causas:

- \
  UTMs não chegaram ao checkout\
- \
  parâmetros configurados incorretamente\
- \
  link de checkout sem parametrização\

---

### Conversão apareceu com valor zerado

Possíveis causas:

- \
  plataforma não enviou valor financeiro\
- \
  configuração incompleta da integração\
