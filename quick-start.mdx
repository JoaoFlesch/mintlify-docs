### Configure sua primeira operação no TrackUp em poucos minutos.

Se esta é sua primeira vez utilizando o TrackUp, este guia vai te mostrar exatamente o caminho mais rápido para configurar toda sua estrutura e preparar sua operação para receber tráfego com rastreamento completo.

Ao final deste processo, você terá:

✓ Um projeto criado\
✓ Um domínio configurado\
✓ Uma página publicada\
✓ Uma oferta conectada\
✓ Um link de rastreamento criado\
✓ Eventos sendo enviados corretamente\
✓ Sua primeira conversão pronta para ser atribuída

---

## Antes de começar

O TrackUp funciona como uma infraestrutura completa para sua operação de tráfego pago.

Todo o fluxo da plataforma segue uma arquitetura simples:

```text
```

```text
Campanha → Link → Página → Checkout → Conversão → Evento → Analytics
```

Cada etapa depende da anterior.

Por isso, recomendamos seguir este guia exatamente na ordem abaixo.

# Passo 1 — Crie seu primeiro Projeto

Todo projeto dentro do TrackUp representa uma operação individual.

Recomendamos utilizar um projeto para cada:

- \
  Produto\
- \
  Funil\
- \
  Oferta\
- \
  Cliente\
- \
  Operação específica\

Exemplo:

```text
```

```text
Time → Agência Atlas

Projeto 1 → Produto Financeiro
Projeto 2 → Produto Nutra
Projeto 3 → Cliente XYZ
```

Para criar um projeto:

1. \
   Acesse o menu lateral\
2. \
   Clique em criar novo projeto\
3. \
   Escolha o nome da operação\
4. \
   Salve a estrutura inicial\

# Passo 2 — Configure seu domínio

Agora precisamos conectar o domínio que será utilizado nas páginas e links.

O TrackUp utiliza subdomínios apontados para nossa infraestrutura DNS.

Você precisará criar um registro:

```text
```

```text
CNAME → cname.trackup-dns.dev
```

Exemplo:

```text
```

```text
go.seudominio.com → cname.trackup-dns.dev
```

Após a propagação, o domínio ficará disponível dentro da plataforma.

---

### Recomendação

Utilize subdomínios diferentes para cada operação.

Exemplo:

```text
```

```text
oferta01.seudominio.com
checkout.seudominio.com
go.seudominio.com
```

# Passo 3 — Crie sua primeira página

Agora vamos criar a página que receberá seus visitantes.

Você possui diferentes opções.

### Builder Visual

Crie páginas utilizando nosso editor completo.

### Upload HTML

Envie arquivos HTML próprios.

### Clonar URL

Clone páginas existentes e publique rapidamente.

### Redirect

Redirecione visitantes para páginas externas mantendo o rastreamento.

---

### Recomendação para iniciantes

Utilize o Builder Visual.

---

Para criar:

1. \
   Acesse Páginas\
2. \
   Clique em criar nova página\
3. \
   Escolha o método desejado\
4. \
   Edite ou envie seus arquivos\
5. \
   Publique no domínio configurado\

# Passo 4 — Configure sua Oferta

A oferta representa o checkout final que receberá a conversão.

Ela conecta o usuário que clicou no anúncio com a venda realizada posteriormente.

Exemplos de plataformas suportadas:

- \
  Upag\
- \
  PerfectPay\
- \
  Hotmart\
- \
  Kiwify\
- \
  Kirvano\

Para criar uma oferta:

1. \
   Acesse Ofertas\
2. \
   Clique em nova oferta\
3. \
   Escolha a plataforma de vendas\
4. \
   Insira a URL do checkout\
5. \
   Salve a configuração\

---

### Importante

Toda atribuição de conversão depende da oferta estar configurada corretamente.

# Passo 5 — Crie seu primeiro Link de rastreamento

Todo o ecossistema do TrackUp começa pelos links.

Os links são responsáveis por:

- \
  Capturar parâmetros da campanha\
- \
  Gerar Click ID\
- \
  Preservar UTMs\
- \
  Associar conversões futuras ao clique original\

Você pode criar três tipos.

### Link Genérico

Redirecionamento simples.

### Link de Anúncio

Criado especificamente para campanhas pagas.

### Link de Checkout

Responsável por conectar o visitante ao checkout final.

---

Para criar:

1. \
   Acesse Links\
2. \
   Clique em novo link\
3. \
   Escolha o tipo\
4. \
   Configure destino\
5. \
   Salve\

---

# Passo 6 — Integre seus Pixels

Agora vamos configurar o recebimento de eventos.

O TrackUp permite enviar eventos para plataformas externas.

Atualmente:

- \
  Meta Ads\

Em breve:

- \
  Google Ads\
- \
  TikTok Ads\
- \
  Kwai Ads\

Eventos padrão disponíveis:

```text
```

```text
ad_click
page_view
start_checkout
conversion
```

Para integrar:

1. \
   Acesse Integrações\
2. \
   Vá em Pixels\
3. \
   Conecte sua plataforma\
4. \
   Escolha os eventos que serão disparados\
5. \
   Salve\

# Passo 7 — Lance sua campanha

Agora sua infraestrutura está pronta.

Pegue o link criado no passo anterior e utilize-o na sua campanha.

Exemplo:

```text
```

```text
Meta Ads
↓
Usuário clica
↓
TrackUp captura parâmetros
↓
Usuário acessa página
↓
Usuário vai para checkout
↓
Conversão é registrada
↓
Evento é enviado
↓
Dados aparecem nos logs
```

A partir daqui, o sistema começa a processar todos os dados automaticamente.

# Passo 8 — Valide sua primeira conversão

Antes de escalar campanhas, valide se todo o fluxo está funcionando corretamente.

Checklist:

✓ O domínio foi conectado\
\
✓ A página foi publicada\
\
✓ A oferta foi criada\
\
✓ O link foi configurado\
\
✓ Os parâmetros estão sendo preservados\
\
✓ O pixel está conectado\
\
✓ Os eventos estão disparando corretamente

Se tudo estiver certo, sua operação já está pronta.

# Fluxo ideal recomendado

Sempre recomendamos utilizar esta estrutura.

```text
```

```text
Meta Ads
↓
Link de anúncio
↓
Landing Page
↓
Link de checkout
↓
Checkout
↓
Conversão
↓
Evento disparado
↓
Analytics atualizados
```

Essa é a arquitetura mais eficiente para manter atribuição precisa e preservar o máximo possível de dados.
