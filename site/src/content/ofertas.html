--- title: Ofertas icon: bag description: A oferta é a página de checkout do seu produto. É por ela que a venda volta atribuída ao anúncio. ---

Uma oferta é uma página com finalidade Checkout, ligada a uma plataforma de venda. Na maioria dos casos ela redireciona para o checkout da plataforma, levando junto o ID do clique e as UTMs. Quando a venda acontece, a plataforma devolve esse ID no webhook e o Trackup liga a venda à campanha.

Criar uma oferta

A oferta precisa de uma plataforma de venda integrada. Se ainda não tem, crie em Integração › Plataformas de vendas ou pelo atalho Criar plataforma de vendas dentro do formulário.

No menu lateral, clique em Ofertas e em Adicionar oferta. A oferta abre em uma página inteira, sem abas. Preencha:

CampoDescrição
NomePor exemplo Checkout Produto X.
Plataforma de vendasA plataforma que processa o pagamento.
URL de redirecionamentoO link do checkout na plataforma. O redirecionamento é temporário (302).
CaminhoOpcional, como /checkout.

Na lista de Ofertas, clique no botão de copiar da coluna Link.

Cole o link como destino de todos os botões de compra das suas páginas. No Builder, é o campo Destino do evento de clique do botão.

Parâmetros repassados ao checkout

Os parâmetros que o visitante trouxe (como utm_source) são repassados para a URL de destino. Se o mesmo parâmetro já existir fixo na URL de redirecionamento, o valor do visitante prevalece. Os parâmetros da plataforma de venda, como o ID do clique, são adicionados automaticamente.

Vários checkouts para o mesmo produto

Crie uma oferta para cada checkout. Um produto pode ter, por exemplo, Product A - Checkout 1 (preço cheio) e Product A - Checkout 2 (preço com desconto, outra cor). Cada oferta tem seu link e seu caminho, e todas aparecem na lista de Ofertas.

Oferta com página própria

Além de Redirect, uma oferta pode ser criada com Builder, Upload HTML ou Clonar URL, por exemplo para um pré-checkout. Nesse caso, o botão dessa página deve levar ao checkout da plataforma.

Testar ofertas

Para comparar dois checkouts (preços, cores, plataformas ou páginas de pagamento diferentes), crie um teste A/B do tipo Checkout com as ofertas como variantes. O botão de compra aponta para o link do teste.

Se um botão apontar direto para o checkout da plataforma, a venda chega sem o ID do clique e aparece como Click ID ausente em Conversões.
