A API dá acesso programático aos mesmos recursos do painel: projetos, páginas, links, pixels, acionadores, domínios, filtro, dashboards, gerenciador de anúncios e dados de tráfego e vendas. Também recebe vendas e eventos de sistemas externos.

https://api.trackup.me/v1 Chave no header X-Api-Key, permissões e projetos. Códigos de status e formato das respostas de erro. Todas as operações, agrupadas por área.

Primeira requisição

Em Configurações › Chaves de API, crie uma chave com a permissão project.list. Veja Chaves de API.

 curl https://api.trackup.me/v1/projects \ -H "X-Api-Key: $TRACKUP_API_KEY" { "data": [ { "id": "11111111-1111-4111-8111-111111111111", "name": "Loja", "slug": "loja", "currency": "BRL" } ], "count": 1 }

Convenções

TemaRegra
FormatoCorpos e respostas em JSON. Envie Content-Type: application/json.
ListagensRetornam { "data": [...], "count": n } e aceitam page (a partir de 1) e limit (até 100, padrão 20).
Datas de consultaYYYY-MM-DD, dias no fuso horário do time. endDate é inclusivo.
FiltrosOnde existe filters, envie um array JSON codificado na URL, combinado com E.
ProjetoQuase tudo é por projeto, no caminho (/projects/{id}/...). Nos endpoints de ingestão, envie projectId no corpo, exceto se a chave tiver um único projeto.
PublicaçãoAlterações em páginas só vão ao ar com publishPage.

Especificação OpenAPI

A especificação completa está em https://api.trackup.me/openapi.json. Use para gerar clientes ou importar no Postman e no Insomnia.

Para usar o Trackup com Claude, ChatGPT ou Cursor sem escrever código, veja Conectar ao MCP.
