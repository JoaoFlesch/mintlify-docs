Ao invés de depender de múltiplas plataformas separadas, o Trackup permite que você construa e gerencie toda sua estrutura diretamente no seu projeto.

# 1. Redirect

A forma mais simples de utilizar páginas dentro do Trackup.

Neste modo, você cadastra uma URL externa e o Trackup utiliza essa página como destino do visitante.

Recomendamos para quem já utiliza hospedagem externa e deseja apenas centralizar sua operação.

Ideal para:

- Páginas já hospedadas externamente
- Operações que não queiram migrar infraestrutura
- Testes rápidos
- Ofertas que já estão em andamento\
  \
  Obs.: Neste caso você precisa instalar o script do Trackup no head da sua página \
  \
  → Continue em [**Redirect**](/redirect)

# 2. Builder

Crie páginas diretamente dentro do Trackup utilizando nosso Page Builder.

Desenvolvido para permitir construção completa de páginas sem necessidade de código.

Você poderá criar praticamente qualquer tipo de pagina utilizando:

- Editor visual
- Blocos prontos
- Templates
- Componentes customizáveis
- Recursos assistidos por IA

Ao criar a página, ela ficará disponível para edição dentro do Builder.

Ideal para:

- Landing pages
- VSLs
- Captura de leads

→ Continue em [**Builder**](/builder)

---

# 3. Upload HTML

Publique páginas próprias enviando arquivos HTML diretamente para o Trackup.

Essa opção é ideal para usuários que já possuem páginas prontas desenvolvidas externamente.

Você pode enviar:

- Arquivo `.html` único
- Arquivo `.zip` contendo estrutura completa

Exemplo:

```text
index.html
style.css
script.js
images
```

O Trackup processará automaticamente os arquivos e publicará sua página.

Ideal para:

- Desenvolvedores
- Landing pages já prontas
- Projetos customizados
- Estruturas exportadas de outras ferramentas

→ Continue em [**Upload HTML**](/upload-html)

# 4. Clonar URL

Copie a estrutura visual de uma página já existente a partir de uma URL pública.

Esse método permite importar páginas externas e utilizar a estrutura dentro do seu projeto.

Com possibilidade de editar o código dela, como se estivesse feito o [**Upload HTML**](/upload-html)

O Trackup irá replicar a estrutura da página para utilização dentro do Trackup.

Ideal para:

- Replicar páginas existentes
- Criar variações rapidamente
- Migrar estruturas externas
- Criar ambientes de teste

→ Continue em [**Clonar URL**](/clonar-url)

# Qual método devo escolher?

A escolha depende do tipo de operação que você deseja montar.

| Cenário | Melhor opção |
| :-- | :-- |
| Já possui página hospedada externamente | [Redirect](/redirect) |
| Quer construir rapidamente sem código | [Builder](/builder) |
| Já possui arquivos HTML prontos | [Upload HTML](/upload-html) |
| Quer replicar uma página existente | [Clonar URL](/clonar-url) |

# Boas práticas

Recomendamos algumas práticas simples.

---

### Utilize nomes descritivos

Evite:

```text
Página 1
Landing nova
teste
```

Prefira:

```text
Landing Principal
VSL Produto Financeiro
Página Pré Checkout
Página Captura Webinar
```

---

### Organize páginas por função

Exemplo:

```text
Landing Principal
VSL Principal
Página de Obrigado
Pré Checkout
Página de Captura
```

---

### Evite misturar páginas de operações diferentes

Mantenha páginas organizadas dentro do projeto correto.

---

### Valide antes de enviar tráfego

Sempre teste a página antes de utilizar campanhas pagas.
