### Importe páginas existentes em segundos e edite toda estrutura diretamente dentro do TrackUp.

Nem sempre você quer começar uma página do zero.

Muitas vezes você encontra uma página que deseja utilizar como base, já possui estruturas espalhadas em outras hospedagens ou simplesmente precisa replicar rapidamente uma página existente.

Foi pensando nisso que criamos o modo **Clonar URL**.

Com ele, você informa uma URL pública, o TrackUp replica automaticamente a estrutura da página e disponibiliza todos os arquivos para edição dentro da plataforma.

Em outras palavras:

> Você transforma qualquer página existente em uma página totalmente editável dentro do seu projeto.

# Como funciona o Clonar URL?

O processo foi criado para ser extremamente simples.

Você escolhe uma página existente na internet.

Informa a URL dentro do TrackUp.

O sistema processa automaticamente a estrutura da página e replica os arquivos para dentro do seu projeto.

Fluxo:

```text
Inserir URL
↓
TrackUp analisa a página
↓
Sistema replica a estrutura
↓
Arquivos são hospedados internamente
↓
Página fica disponível para edição
```

Sem precisar copiar arquivos manualmente.

Sem precisar reconstruir páginas do zero.

# O que acontece após o clone?

Após concluir o processo, a página deixa de depender do endereço original.

Toda estrutura passa a existir dentro do próprio TrackUp.

Isso significa que você passa a ter controle total sobre os arquivos importados.

Exemplo.

Se você clonar:

```text
https://pagina-exemplo.com
```

Após o processamento:

```text
TrackUp cria uma cópia local completa

HTML importado

CSS importado

JavaScript importado

Assets importados

Arquivos disponíveis no projeto
```

A partir desse momento, a página passa a ser sua estrutura hospedada.

---

# Edição completa após a clonagem ✏️

Depois que o clone é concluído, todos os arquivos ficam disponíveis dentro do gerenciador interno do TrackUp.

Você poderá visualizar toda estrutura importada.

Exemplo.

```text
Landing Clonada

├── index.html
├── style.css
├── script.js
├── assets/
│      ├── banner.webp
│      ├── logo.png
│      └── icons/
```

A estrutura fica totalmente acessível.

# Clonar URL vs Upload HTML

Embora pareçam similares, existem diferenças importantes.

| Se você quer… | Melhor opção |
| :-- | :-- |
| Enviar arquivos próprios | Upload HTML |
| Importar uma página já existente na internet | Clonar URL |
| Editar arquivos manualmente | Ambos |
| Hospedar arquivos dentro do TrackUp | Ambos |
| Replicar páginas sem precisar dos arquivos originais | Clonar URL |

A diferença principal está na origem dos arquivos.
