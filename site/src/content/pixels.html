--- title: Pixels icon: pixel description: Conecte sua conta de anúncios para enviar os eventos do funil pelo servidor (API de conversões). ---

Configure pela sua IA. Conecte seu assistente pelo MCP e peça: "Crie um pixel Meta com acionadores de pageview, início de checkout e conversão."

Um pixel guarda as credenciais da API de conversões de uma plataforma de anúncios. Os acionadores usam o pixel para enviar eventos do funil, como page_view, start_checkout e conversion, direto do servidor do Trackup. Isso evita perdas por bloqueadores de anúncio e navegadores com restrição de cookies.

Tipos disponíveis: Meta, Google Ads, TikTok e Kwai. O exemplo abaixo usa Meta; os outros tipos seguem o mesmo fluxo e mudam só os campos.

Adicionar um pixel

Vá em Integração › Pixels e clique em Adicionar pixel.

Selecione o Tipo e dê um Nome que identifique a conta, como Meta · Online Store.

Copie os campos da plataforma de anúncios (veja a tabela por plataforma abaixo) e cole no Trackup. Mantenha Ativo ligado.

Clique em salvar. Para Meta, TikTok e Kwai o Trackup cria junto os acionadores Pageview, Start checkout e Conversão e mostra a notificação Pixel e acionadores criados. No Google Ads, crie os acionadores com a conversion label de cada etapa.

O pixel aparece em Integração › Pixels. Se houver Test Event Code, o pixel é marcado como modo teste.

Campos por plataforma

Test Event Code opcionalGerenciador de Eventos › Testar eventos.

Com o Test Event Code preenchido, os eventos vão só para Test Events e não contam nas campanhas. O pixel aparece marcado como modo teste na lista. Apague o código para ir para produção.

Testar a conexão

  1. Preencha o Test Event Code do Meta e salve.
  2. Acesse uma página do projeto com ?utm_source=facebook na URL.
  3. No Gerenciador de Eventos, abra Testar eventos e confirme o PageView recebido pelo servidor.
  4. Em Logs › Logs de acionadores, filtre por Status Sucesso e abra o disparo para ver o request e o response.
  5. Apague o Test Event Code e salve para enviar eventos de produção.

Servidor ou navegador

Por padrão os eventos vão pelo servidor (API de Conversões), o que evita perdas por bloqueadores de anúncio. No acionador você também pode ativar o disparo pelo navegador, disponível só para Meta e TikTok.

PlataformaServidorNavegador
MetaSimSim
TikTokSimSim
Google AdsSimNão
KwaiSimNão

Desativar um pixel

Edite o pixel e desligue Ativo. Os acionadores param de enviar eventos para ele, sem perder a configuração.
