### Conecte suas plataformas de tráfego e atribua todos eventos com precisão.

Os Pixels são responsáveis por conectar o Trackup às plataformas de mídia utilizadas na sua operação.

Sempre que um evento acontece dentro da jornada do usuário, o Trackup pode enviar essas informações diretamente para a plataforma correspondente.

Exemplo:

```text
Usuário clicou no anúncio
↓
Trackup registrou acesso
↓
Evento foi processado
↓
Acionador foi executado
↓
Pixel recebeu o evento
↓
Plataforma aprende com aquele comportamento
```

# Gerenciamento de Pixels

A página principal exibe todos os Pixels conectados ao seu projeto.

Cada integração cadastrada aparece em uma lista central com informações essenciais.

Exemplo de dados exibidos:

```text
Nome do Pixel
Plataforma vinculada
Status da integração
Data de criação
```

Exemplo:

```text
PIXEL_META_Trackup
Plataforma → Meta
Status → Ativo
Criado em → 23/04/2026
```

Aqui você consegue gerenciar todas as integrações ativas do projeto.

# Adicionando um novo Pixel

Para conectar uma nova plataforma basta clicar em:

```text
+ Adicionar Pixel
```

Ao iniciar a configuração, o Trackup abre um painel lateral com os parâmetros necessários para integração.

O formulário se adapta automaticamente dependendo da plataforma escolhida.

Isso significa que cada integração exibe apenas os campos realmente necessários.

O processo fica muito mais simples.

---

# Plataformas suportadas

Atualmente o Trackup suporta integração com múltiplas plataformas de mídia.

Todas funcionam dentro da mesma lógica central.

Cada uma possui parâmetros específicos de autenticação.

---

# Meta Ads

Integração com o ecossistema da Meta para envio de eventos através da API de Conversões.

Campos normalmente utilizados:

```text
Pixel ID

Access Token

Test Event Code (opcional)
```

O Trackup utiliza esses dados para enviar eventos diretamente para os servidores da Meta.

Ideal para melhorar atribuição e alimentar campanhas de conversão.

# Google Ads

Integração com o ecossistema Google para registrar conversões diretamente nas campanhas.

Campos normalmente utilizados:

```text
Conversion ID

Moeda padrão (ISO 4217)

Valor padrão da conversão
```

Exemplo:

```text
AW-123456789

Currency → BRL

Default Value → 0.00
```

Esses dados permitem registrar conversões corretamente dentro da conta Google Ads.

---

# Kwai Ads

Integração com a plataforma de anúncios do Kwai.

Assim como outras plataformas, permite envio direto de eventos para campanhas.

Campos normalmente utilizados:

```text
Pixel ID

Access Token

Test Event Code
```

No ecossistema Kwai, o código de teste possui papel importante durante validação de eventos.

Especialmente em cenários onde identificadores adicionais não estão disponíveis.

---

**\[IMAGEM RECOMENDADA\]**

_(Utilizar print do formulário Kwai mostrando Pixel ID \+ Token \+ Test Event Code obrigatório.)_

# TikTok Ads

Integração com o ecossistema de anúncios do TikTok.

Permite enviar eventos relacionados ao comportamento do visitante e conversões geradas dentro da operação.

Campos normalmente utilizados:

```text
Pixel ID

Access Token

Event configuration parameters
```

A lógica de funcionamento segue o mesmo padrão das demais integrações.

Trackup envia os eventos automaticamente conforme a jornada acontece.

---

# Integração total com Acionadores

Pixels trabalham diretamente conectados ao módulo de Acionadores.

Fluxo:

```text
Evento acontece
↓
Acionador valida condições
↓
Ação é executada
↓
Pixel envia evento para plataforma
```

Sem Acionadores, os Pixels ficam sem função.

Com Acionadores, eles começam a trabalhar.

Esses dois módulos funcionam juntos.

---

# Server-side por padrão ⚡

Sempre que possível, o Trackup prioriza envio server-side.

Isso significa que os eventos são enviados diretamente pelos nossos servidores.

Benefícios:

- maior confiabilidade
- menos bloqueios por adblockers
- melhor atribuição
- maior taxa de entrega de eventos
- dados mais consistentes

A plataforma foi construída priorizando esse modelo.
