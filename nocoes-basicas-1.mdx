# O que acontece quando alguém clica no seu anúncio?

Quando uma pessoa interage com sua campanha, uma sequência inteira de eventos começa a acontecer em segundos.

Não é apenas um clique.

É o início de uma jornada de dados.

O fluxo normalmente acontece assim:

```text
Anúncio → Clique → Página → Navegação → Checkout → Conversão → Evento → Plataforma recebe os dados
```

Cada etapa gera informações extremamente importantes.

Esses dados ajudam plataformas como Meta e Google a entender quem converteu e otimizar futuras campanhas.

# O que é um Pixel?

Um Pixel é um mecanismo utilizado por plataformas de mídia para registrar ações realizadas pelos usuários.

Exemplo:

Quando alguém acessa sua página, o pixel pode registrar:

- Visualização de página
- Clique em botão
- Início de checkout
- Compra finalizada

Essas informações são utilizadas pelas plataformas para entender o comportamento dos usuários.

Exemplos conhecidos:

- Meta Pixel
- TikTok Pixel
- Google Tag

Em resumo:

> O Pixel ajuda a plataforma de anúncios a aprender quem tem mais chance de converter.

---

# O problema do Pixel tradicional

O Pixel tradicional depende do navegador do usuário.

E isso gera vários problemas.

Hoje muitos navegadores bloqueiam rastreamento.

Exemplo:

- Safari
- Brave
- Firefox
- Ad blockers
- Sistemas de privacidade do iOS\

Isso significa que parte dos seus eventos pode simplesmente não chegar até a plataforma.

O resultado:

- Dados incompletos
- Otimização ruim
- Campanhas tomando decisões erradas\

# O que é atribuição?

Atribuição é o processo de identificar qual campanha gerou determinada conversão.

Exemplo:

Imagine que um usuário:

1. Clicou no seu anúncio no Meta Ads
2. Visitou sua landing page
3. Entrou no checkout
4. Comprou o produto\

A atribuição responde:

> Qual campanha gerou essa venda?

Sem atribuição correta, você não consegue saber de onde seu resultado está vindo.

---

# O que são UTMs?

UTMs são parâmetros adicionados na URL para identificar a origem do tráfego.

Exemplo:

```text
https://pagina.com/?utm_source=facebook&utm_campaign=teste01
```

Esses parâmetros ajudam a identificar informações como:

- Origem do tráfego
- Nome da campanha
- Criativo utilizado
- Público utilizado
- Estratégia utilizada\

Exemplo comum:

```text
utm_source=facebook
utm_campaign=escala_junho
utm_content=criativo_video_03
```

---

# O que são Click IDs?

Além das UTMs, plataformas também geram identificadores únicos para cada clique.

Exemplos:

```text
fbclid
gclid
ttclid
```

Esses identificadores ajudam a associar um clique específico com uma futura conversão.

Em outras palavras:

Cada clique possui sua própria identidade.

---

# O que é o Click ID do TrackUp?

Quando um visitante passa por um link criado dentro do TrackUp, o sistema gera um identificador único interno.

Exemplo:

```text
trk_91f8ab72d31
```

Esse identificador acompanha toda a jornada do visitante.

Ele conecta:

- O clique inicial
- A navegação nas páginas
- O checkout
- A conversão final

Isso permite manter a atribuição muito mais precisa.

# O que significa preservar parâmetros?

Quando um usuário navega entre páginas e checkouts, informações importantes precisam continuar sendo transportadas.

Exemplo:

Se o visitante clicou em:

```text
utm_source=facebook
fbclid=123456
```

Essas informações precisam continuar existindo quando ele:

- Navega entre páginas
- Vai para checkout
- Finaliza a compra\

Se esses dados forem perdidos, a atribuição pode quebrar.

Isso significa que a plataforma de anúncios pode deixar de identificar corretamente a conversão.

---

# O que é rastreamento?

Rastreamento significa registrar toda jornada do visitante.

Exemplo:

```text
Usuário clicou no anúncio às 10:42
↓
Visitou landing page
↓
Permaneceu por 3 minutos
↓
Clicou no botão
↓
Entrou no checkout
↓
Finalizou a compra
```

Cada ação gera dados.

Esses dados ajudam você a entender exatamente o que aconteceu.

---

# O que é Fingerprint?

Fingerprint é uma tecnologia utilizada para identificar visitantes utilizando características do dispositivo.

Exemplo de dados analisados:

- Navegador
- Sistema operacional
- Resolução da tela
- Idioma
- Timezone
- Device type
- Informações do navegador\

Isso ajuda o sistema a reconhecer visitantes mesmo em cenários onde cookies tradicionais podem falhar.

---

# O que são Eventos?

Eventos representam ações importantes realizadas pelos usuários.

No TrackUp, alguns eventos padrão são:

```text
ad_click
page_view
start_checkout
conversion
```

Exemplo:

Quando alguém acessa sua landing page:

```text
page_view
```

Quando alguém inicia checkout:

```text
start_checkout
```

Quando alguém compra:

```text
conversion
```

Esses eventos podem ser enviados para plataformas externas.

---

# Como o TrackUp conecta tudo isso?

TrackUp foi criado para unificar toda infraestrutura necessária para operar campanhas de tráfego pago com dados confiáveis.

Quando um visitante entra na sua operação:

```text
Usuário clica no anúncio
↓
TrackUp captura parâmetros
↓
TrackUp gera Click ID
↓
Usuário acessa landing page
↓
TrackUp registra navegação
↓
Usuário vai para checkout
↓
Conversão acontece
↓
TrackUp recebe confirmação
↓
Evento é disparado
↓
Dados aparecem nos logs
```

Todo esse fluxo acontece em poucos segundos.

# Por que isso importa?

Quanto melhores forem seus dados, melhores serão suas decisões.

Quando você entende exatamente:

- Quem clicou
- De onde veio o visitante
- Qual campanha converteu
- Qual criativo performou melhor
- Quanto custa cada conversão real

Você consegue escalar campanhas com muito mais segurança.
