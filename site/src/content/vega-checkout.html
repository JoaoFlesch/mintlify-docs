--- title: Vega Checkout icon: cart eyebrow: Plataformas de venda description: Receba vendas, reembolsos e chargebacks da Vega Checkout no Trackup, atribuídos ao anúncio de origem. ---

A integração tem duas partes: o Trackup envia o ID do clique para o checkout da Vega Checkout, e a Vega Checkout devolve esse ID no webhook de cada venda.

Antes de começar

  • Um projeto com domínio primário configurado. A URL do webhook usa esse domínio.
  • Acesso de administrador à sua conta na Vega Checkout.

1. Crie a plataforma no Trackup

Vá em Integração › Plataformas de vendas, clique em Adicionar plataforma e escolha Vega Checkout.

O Trackup preenche os parâmetros do checkout sozinho: o ID do clique vai em src e as UTMs vão junto. Só mude se a Vega Checkout pedir outro nome de parâmetro.

Salve. Na lista de plataformas, copie a URL da Vega Checkout.

2. Cadastre o webhook na Vega Checkout

  1. Desenvolvedores/Webhooks
  2. Nova integração
  3. Adicionar um nome para a integração
  4. Cole a URL do Trackup
  5. Marque os Eventos (Venda Aprovada, Venda Chargeback, Venda Estornada)
  6. Restrinja produtos caso necessário
  7. Salve

3. Teste

Acesse sua landing page por um link do Trackup, clique no botão de compra e faça uma compra de teste. A venda deve aparecer em Logs › Conversões com a campanha preenchida.

Se a venda aparecer como Click ID ausente, o botão da página não está apontando para o link da oferta no Trackup, ou o checkout não está devolvendo o parâmetro do clique.

Não achou sua plataforma? Use o webhook genérico.
