--- title: Projetos icon: layers description: Um projeto reúne domínios, páginas, pixels, regras e relatórios de uma operação. ---

Crie um projeto para cada produto, oferta ou cliente. Os dados de um projeto não se misturam com os de outro: cada um tem seus domínios, suas páginas, seus pixels e seus dashboards.

Um projeto novo, sem dados, mostra o guia Crie seu primeiro projeto com quatro etapas: criar o projeto, conectar as fontes (pixels, fontes de tráfego e plataformas de venda), proteger as páginas (domínio próprio e filtro) e acompanhar os resultados.

Criar um projeto

No topo do menu lateral, clique no projeto atual e em Criar projeto. No primeiro acesso, use o botão do estado vazio.
CampoDescrição
NomeComo o projeto aparece no painel, por exemplo Online Store.
URLIdentificador inicial do projeto (slug), usado em links e scripts. Use letras minúsculas, números e hífen.
MoedaMoeda dos relatórios. Vendas em outra moeda são convertidas pelo câmbio do dia nos webhooks. Não pode ser alterada depois.

O projeto é criado com um domínio padrão do Trackup, que já serve páginas e links. Configure um domínio próprio antes de anunciar.

Configurações do projeto

Em Ajustes › Geral você encontra:

SeçãoO que faz
ProjetoAltera o nome e a URL do projeto, usada em links e scripts.
Segurança › Domínios permitidosLista os sites autorizados a enviar eventos pelo script. yourdomain.com libera só o domínio raiz; *.yourdomain.com, só os subdomínios. Para liberar os dois, adicione as duas entradas. Vazia, libera todos.
Segurança › Snippet de rastreamentoCódigo para instalar em páginas fora do Trackup, com um snippet por domínio. Veja Script de rastreamento.
Excluir projetoRemove o projeto e todos os dados dele.

Excluir um projeto apaga páginas, links, regras, logs e conversões de forma permanente. Não há como desfazer.

Dashboard do projeto

A tela inicial do projeto é o dashboard. Ele mostra lucro (faturamento, despesas e ROAS), vendas do período atual contra o anterior, funil, status de pagamentos, acessos por origem, dispositivo e horário, e visitantes reais contra bots. Veja como montar o seu em Dashboards.

Alternar entre projetos

Use o seletor no topo do menu lateral. Tudo que aparece no menu (dashboards, páginas, logs, integrações) se refere ao projeto selecionado.
