# Segurança

Esta seção controla quais domínios podem enviar dados para o projeto e disponibiliza o script principal de rastreamento.

---

## Domínios Permitidos

Define quais domínios estão autorizados a enviar eventos para este projeto.

Exemplo:

```text
lp.seudominio.com
oferta.site.com
checkout.xyz
```

Quando configurado:

```text
Apenas estes domínios poderão enviar dados.
```

Se vazio:

```text
Qualquer domínio poderá enviar eventos.
```

Recomendado utilizar em produção.

## Tracking Snippet

Script principal responsável por enviar dados para o TrackUp.

Sem ele, o projeto não recebe eventos.

O snippet deve ser instalado dentro da tag:

```html
<head>
```

Exemplo:

```html
<head>
  <script>
    TRACKUP SCRIPT
  </script>
</head>
```

---

## O que o snippet coleta?

Após instalado, o sistema começa capturar automaticamente:

- page views
- cliques
- parâmetros UTM
- click IDs
- dispositivo
- navegador
- localização
- eventos automáticos

Fluxo:

```text
Visitante acessa página
↓
Snippet executa
↓
TrackUp recebe evento
↓
Visitor é criado
```

## Validando instalação

Após instalar o snippet, acesse:

```text
Requisições
ou
Visitors
```

Se configurado corretamente, novos acessos começarão a aparecer automaticamente.

# Excluir Projeto

Remove permanentemente todo o projeto e seus dados.

Serão removidos:

- páginas
- links
- pixels
- integrações
- visitors
- requisições
- conversões
- histórico financeiro

### Atenção

Esta ação é irreversível.

Após excluir, os dados não poderão ser recuperados.
