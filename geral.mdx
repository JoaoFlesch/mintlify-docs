É nesta página que você configura as informações fundamentais que sustentam todo ecossistema do seu projeto.

Em outras palavras:

> Aqui ficam as configurações que fazem seu projeto existir e funcionar corretamente.

Alterações realizadas nesta área impactam diretamente todos os módulos da plataforma.

# Seção 1 — Projeto

A primeira seção concentra as informações principais de identificação do seu projeto.

Aqui você define os parâmetros globais utilizados em toda operação.

Campos disponíveis:

```text
Nome do Projeto

Moeda padrão
```

Essas configurações são aplicadas automaticamente em diversos módulos internos.

---

# Nome do Projeto

O nome do projeto serve para identificar sua operação dentro do ecossistema TrackUp.

Exemplo:

```text
Trackup
```

Recomendamos utilizar nomes que representem claramente o produto, funil ou operação vinculada ao projeto.

Exemplos:

```text
Produto Principal

Funil Black Friday

Campanha Lead Generation

Oferta Nutra Brasil
```

Uma boa organização facilita o gerenciamento quando você trabalha com múltiplos projetos.

---

# Moeda padrão 💰

A moeda define qual unidade financeira será utilizada internamente no projeto.

Exemplo:

```text
BRL — Real Brasileiro
```

Essa configuração influencia diretamente:

- relatórios financeiros
- processamento de webhooks
- cálculo de receita
- dashboard de faturamento
- conversões registradas

Sempre que uma plataforma de venda enviar valores monetários, o TrackUp utilizará essa moeda como referência principal.

---

### Importante

A moeda do projeto **não pode ser alterada após a criação**.

Isso acontece porque toda estrutura financeira do sistema depende desta configuração.

Exemplo:

```text
Webhook envia valor

↓

TrackUp converte valor recebido

↓

Sistema registra receita no dashboard

↓

Conversão utiliza moeda definida no projeto
```

Alterar isso posteriormente poderia comprometer a consistência dos dados financeiros.

# Seção 2 — Segurança

Esta é uma das áreas mais importantes de toda plataforma.

Aqui ficam as configurações responsáveis por ativar a infraestrutura técnica de rastreamento.

Sem esta configuração, o TrackUp não consegue receber dados do seu site.

Essa seção controla:

```text
Domínios autorizados

Snippet de rastreamento

Recebimento de eventos

Validação de tráfego
```

Esta é basicamente a camada que conecta seu site ao ecossistema TrackUp.

---

# Domínios Permitidos 🔐

O campo de Domínios Permitidos funciona como uma camada extra de segurança.

Seu objetivo é definir quais sites possuem autorização para enviar eventos ao projeto.

Exemplo:

```text
seudominio.com

oferta.com.br

landing-page.xyz
```

Quando configurado, o sistema aceitará eventos apenas destes domínios.

Qualquer outro domínio será ignorado.

---

### Por que isso é importante?

Sem restrição de domínio, qualquer site poderia teoricamente tentar enviar dados ao seu projeto.

Isso pode gerar:

- eventos falsos
- poluição de dados
- requisições inválidas
- problemas de segurança

Ao limitar domínios autorizados, você protege toda operação.

---

### Se o campo ficar vazio

Caso nenhum domínio seja configurado:

```text
O sistema aceitará dados de qualquer domínio.
```

Isso normalmente não é recomendado em operações de produção.

# Snippet de Rastreamento

O snippet é o script principal responsável por conectar seu site ao TrackUp.

Pense nele como o ponto inicial de toda coleta de dados.

Sem ele:

```text
Nenhum visitante será identificado

Nenhuma requisição será registrada

Nenhum evento será enviado

Nenhum tracking acontecerá
```

Este script precisa ser instalado nas páginas que fazem parte da operação.

---

# Onde instalar o snippet?

O código deve ser inserido dentro da tag:

```html
<head>
```

Exemplo:

```html
<html>

<head>

<script>
TRACKUP SCRIPT
</script>

</head>
```

Sempre posicione o script no início do carregamento da página.

---

# O que o snippet faz?

Quando instalado corretamente, o snippet começa automaticamente a coletar dados de navegação.

Exemplo do que ele captura:

```text
Page Views

Cliques

Dados de dispositivo

Dados do navegador

Localização aproximada

Parâmetros UTM

Click IDs

Eventos automáticos
```

Fluxo:

```text
Usuário acessa página

↓

Snippet executa

↓

TrackUp recebe requisição

↓

Visitor é criado

↓

Dados começam a ser processados
```

Esse é o primeiro passo de toda infraestrutura de tracking.

# Como saber se o snippet está funcionando?

Após instalar o código, você pode validar acessando os módulos:

```text
Requisições

ou

Visitors
```

Se tudo estiver correto, novas visitas começarão a aparecer automaticamente.

```text

↓

↓

↓

Visitor é criado automaticamente
```

Se nenhum dado aparecer, revise a instalação.

---

# Excluir Projeto

Ao excluir um projeto, todos dados vinculados a ele serão apagados permanentemente.

Isso inclui:

```text
Páginas

Links

Pixels

Fontes de tráfego

Integrações

Logs de requisições

Visitors

Conversões

Eventos registrados

Histórico financeiro
```

Nenhuma informação poderá ser recuperada posteriormente.

---

### Importante

Esta ação é irreversível.

Fluxo:

```text
Excluir projeto

↓

Sistema remove toda infraestrutura

↓

Todos dados são apagados

↓

Operação deixa de existir permanentemente
```

Não existe restauração após a exclusão.
