Todo projeto no Trackup recebe um domínio padrão automaticamente.

Porém, recomendamos conectar um domínio próprio para utilizar toda infraestrutura da plataforma com maior controle e isolamento.

Os domínios conectados serão utilizados em módulos como:

```text
Páginas

Links

Redirects

Builder

Upload HTML

Clonar URL

Tracking
```

Sem um domínio conectado, parte da infraestrutura pública do projeto ficará limitada.

# Como os domínios funcionam

Sempre que você publica qualquer estrutura dentro do Trackup, o Trackup precisa de um domínio para servir esse conteúdo.

Exemplo:

- páginas hospedadas
- links de tracking
- redirects
- páginas criadas no builder
- páginas clonadas
- arquivos HTML hospedados

Todo tráfego passa pela infraestrutura conectada ao domínio configurado.

# Recomendação: utilize subdomínios

Recomendamos utilizar **subdomínios dedicados** para cada operação.

Exemplo:

```text
lp.seudominio.com
track.seudominio.com
go.seudominio.com
offer.seudominio.com
```

Benefícios:

- melhor organização
- isolamento da infraestrutura
- gerenciamento DNS mais simples
- separação entre site institucional e campanhas
- maior flexibilidade operacional

Evite utilizar o domínio principal sempre que possível.

---

# Lista de domínios

A página principal exibe todos os domínios conectados ao projeto.

Cada domínio possui:

- status de verificação
- data de criação
- definição de domínio primário
- ações de gerenciamento

Exemplo:

```text
lp.Trackup.me          Verificado ✓
track.meudominio.com  Verificado ✓
```

Um projeto pode possuir múltiplos domínios ativos simultaneamente.

# Domínio primário

Quando múltiplos domínios estão conectados, um deles pode ser definido como padrão.

O domínio primário será utilizado automaticamente em:

- criação de links
- novas páginas
- redirects
- URLs padrão do projeto

Exemplo:

```text
⭐ lp.meudominio.com
```

Os demais domínios continuam funcionando normalmente.

---

# Adicionando um domínio

Para conectar um novo domínio:

```text
+ Adicionar Domínio
```

Informe o hostname desejado.

Exemplo:

```text
track.seudominio.com
```

Após salvar, o Trackup irá gerar a configuração DNS necessária.

---

# Configuração DNS

Após criar o domínio, o status ficará como:

```text
Pendente
```

Agora será necessário configurar o DNS no seu provedor.

Exemplos:

- Cloudflare
- GoDaddy
- Hostinger
- HostGator

O registro necessário será:

```text
Tipo: CNAME
```

Exemplo:

```text
Nome: track

Destino: cname.Trackup-dns.com
```

Exemplo final:

```text
track.seudominio.com
↓

cname.Trackup-dns.com
```

O painel disponibiliza botões de cópia rápida para facilitar a configuração.

---

**\[IMAGEM RECOMENDADA\]**

_(Tabela DNS com Name \+ Target \+ botão copiar.)_

---

# Verificando o domínio

Após configurar o DNS, clique em:

```text
Verificar
```

O Trackup irá validar publicamente o apontamento.

Se tudo estiver correto:

```text
Status → Verificado ✓
```

A partir desse momento o domínio já pode ser utilizado em toda plataforma.

---

**\[IMAGEM RECOMENDADA\]**

# Status pendente

Se o domínio continuar pendente, normalmente significa:

- DNS ainda propagando
- CNAME configurado incorretamente
- apontamento feito no registro errado
- proxy DNS configurado incorretamente

Enquanto estiver pendente, o domínio não poderá ser utilizado.

---

# Múltiplos domínios

Você pode conectar quantos domínios quiser no mesmo projeto.

Exemplo:

```text
lp.meusite.com
go.meusite.com
track.meusite.com
offer.meusite.com
```

Isso permite separar diferentes operações dentro do mesmo projeto.

---

# Fluxo de funcionamento

```text
Adicionar domínio
↓
Trackup gera CNAME
↓
Configurar DNS
↓
Validar domínio
↓
Status muda para verificado
↓
Domínio fica disponível na plataforma
```

---

# Resumo

O módulo de domínios conecta sua infraestrutura ao ambiente público.

```text
Domínio
↓
DNS
↓
Validação
↓
Publicação
↓
Tracking ativo
```

Páginas, links e toda estrutura pública do projeto dependem dessa configuração.
