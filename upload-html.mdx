### Publique páginas próprias, gerencie arquivos e edite seu código diretamente dentro do TrackUp.

Nem toda operação utiliza construtores visuais.

Muitos usuários já possuem páginas desenvolvidas externamente e precisam apenas de uma infraestrutura rápida, confiável e centralizada para publicar e gerenciar esses arquivos.

Foi exatamente para isso que criamos o módulo **Upload HTML**.

Com ele, você pode enviar suas próprias páginas, hospedar seus arquivos dentro do TrackUp e gerenciar toda estrutura diretamente pela plataforma.

Mas não para por aí.

Além do upload, o TrackUp oferece um ambiente interno de gerenciamento de arquivos com edição direta de código.

Em outras palavras:

> Você pode publicar, editar e gerenciar toda sua estrutura HTML sem sair do TrackUp.

# Para quem o Upload HTML foi criado?

Esse modo foi desenvolvido principalmente para usuários que já possuem páginas prontas e desejam manter controle técnico total sobre a estrutura.

Ideal para:

- Desenvolvedores
- Designers
- Afiliados que compram páginas prontas
- Operações que utilizam landing pages customizadas
- Equipes técnicas que precisam editar código diretamente

Se você já possui uma página pronta, não existe necessidade de reconstruí-la no Builder.

Basta enviar seus arquivos.

---

# Como funciona o Upload HTML?

Ao criar uma página utilizando esse método, você envia os arquivos responsáveis pela estrutura da página.

O sistema processa automaticamente o conteúdo e publica a página dentro do seu projeto.

Você pode enviar dois formatos.

### Arquivo HTML único

Ideal para páginas simples.

Exemplo:

```text
```

```text
landing.html
```

---

### Arquivo ZIP

Ideal para páginas completas contendo múltiplos arquivos.

Exemplo:

```text
```

```text
index.html
style.css
script.js
images/
fonts/
assets/
```

Após o envio, o sistema organiza e publica automaticamente sua estrutura.

# Hospedagem integrada no próprio TrackUp

Quando você envia sua página, os arquivos passam a ser hospedados diretamente dentro da infraestrutura do TrackUp.

Isso significa que você não precisa depender de serviços externos para manter sua página online.

Todo o gerenciamento fica centralizado dentro do seu projeto.

Benefícios.

✓ Sem depender de hospedagens externas\
\
✓ Estrutura centralizada\
\
✓ Gerenciamento unificado\
\
✓ Deploy simplificado\
\
✓ Menos ferramentas externas na operação

Sua página passa a fazer parte do ecossistema completo do projeto.

---

# Gerenciador de arquivos integrado 📂

Depois que sua página é enviada, todos os arquivos ficam disponíveis dentro do ambiente interno de gerenciamento.

Você poderá visualizar toda estrutura da página hospedada.

Exemplo.

```text
```

```text
Minha Landing

├── index.html
├── style.css
├── script.js
├── assets/
│      ├── logo.png
│      ├── banner.webp
│      └── icon.svg
│
└── fonts/
```

Todo arquivo fica acessível para gerenciamento posterior.

# Fluxo completo de publicação

O processo foi pensado para ser extremamente simples.

```text
```

```text
Criar página
↓
Selecionar Upload HTML
↓
Enviar HTML ou ZIP
↓
TrackUp processa arquivos
↓
Página publicada
↓
Arquivos ficam disponíveis no gerenciador
↓
Editar código quando necessário
```

Sem processos complexos de deploy.

# Quando utilizar Upload HTML?

Essa opção é ideal quando você já possui páginas desenvolvidas externamente.

Exemplo.

Você comprou uma landing page pronta.

Ou sua equipe desenvolveu uma página customizada.

Ou você exportou uma página de outra ferramenta.

Nesses casos, o Upload HTML costuma ser a melhor opção.

---

# Upload HTML vs Builder

Ambos criam páginas, mas possuem objetivos diferentes.

| Se você quer… | Melhor opção |
| :-- | :-- |
| Criar páginas visualmente | Builder |
| Criar páginas com IA | Builder |
| Utilizar templates | Builder |
| Publicar páginas já desenvolvidas | Upload HTML |
| Editar código manualmente | Upload HTML |
| Gerenciar arquivos diretamente | Upload HTML |

A escolha depende do seu fluxo operacional.
