# Quando utilizar Redirect?

O modo Redirect é ideal quando sua página já está publicada em outro lugar e você não deseja reconstruí-la dentro do Trackup.

Exemplos comuns.

Você possui uma landing page hospedada em:

- VPS própria
- WordPress
- Cloudflare Pages
- Vercel
- Hospedagem tradicional
- Qualquer outra infraestrutura externa

Em vez de migrar essa página, você simplesmente conecta ela ao seu projeto.

---

# Como criar uma página Redirect

Criar uma página via Redirect leva apenas alguns segundos.

Você precisará informar duas informações.

**\[IMAGEM RECOMENDADA\]**

_(Mesmo print do modal, mas agora com pequenas marcações ou zoom destacando cada campo individualmente.)_

### Nome

Utilize um nome fácil de identificar dentro do projeto.

Exemplos:

- Landing Principal
- VSL Principal
- Página de Captura
- Pré Checkout

---

### URL de Redirecionamento

Aqui você informará a URL da página externa que receberá o visitante.

Exemplo:

```text
https://meusite.com
```

Após salvar, a página ficará disponível dentro do seu projeto.
