Sempre que alguém acessa sua operação através de mídia paga, o link carrega parâmetros na URL.

Exemplo:

```text
utm_source=facebook
utm_campaign=campanha_teste
utm_medium=conjunto_01
utm_content=criativo_video_03
fbclid=ABCD123456
```

Esses parâmetros são extremamente importantes.

Eles permitem que o Trackup descubra:

```text
Qual campanha gerou o clique
Qual conjunto de anúncios originou a visita
Qual anúncio foi exibido
Qual criativo trouxe o usuário
```

Sem isso, o Trackup fica sem contexto.

# Adicionando uma nova Fonte de Trafego

Para configurar uma nova plataforma basta clicar em:

```text
+ Adicionar Fonte
```

O Trackup exibe um construtor dinâmico de parâmetros.

Cada mídia possui sua própria forma de construir URLs.

Para facilitar o processo, o Trackup já pré-configura automaticamente os valores recomendados.

Você não precisa montar manualmente.

**\[IMAGEM RECOMENDADA\]**

_(Diagrama mostrando Ad Platform → URL Parameters → Trackup Receives Parameters → Request → Visitor → Conversion Attribution.)_

## Meta

Ao selecionar Meta, o Trackup utiliza automaticamente as macros oficiais do ecossistema da Meta.

```text
Parâmetro -> Placeholder ou valor
utm_source = meta
utm_medium = {{adset.name}}|{{adset.id}}
utm_campaign = {{campaign.name}}|{{campaign.id}}
utm_content = {{ad.name}}|{{ad.id}}
utm_term = {{placement}}
trk_cmpid = {{campaign.id}}
trk_asid = {{adset.id}}
trk_aid = {{ad.id}}
```

---

## Google

Ao selecionar Google, o Trackup utiliza automaticamente as macros oficiais do ecossistema da Google.

```text
Parâmetro -> Placeholder ou valor
utm_source = google
utm_medium = cpc
utm_campaign = {campaignid}
utm_content = {creative}
utm_term = {keyword}
trk_cmpid = {campaignid}
trk_asid = {adgroupid}
trk_aid = {creative}
```

---

## Kwai

Ao selecionar Kwai, o Trackup utiliza automaticamente as macros oficiais do ecossistema da Kwai.

```text
Parâmetro -> Placeholder ou valor
utm_source = kwai
utm_medium = cpc
utm_campaign = __CMPN__
utm_term = __ADSET__
utm_content = __AD__
trk_cmpid = __CMPNID__
trk_asid = __ADSETID__
trk_aid = __ADID__
```

# Crie parâmetros personalizados

Além dos templates padrões, você também pode adicionar parâmetros completamente personalizados.

Isso permite adaptar o Trackup para operações específicas.

Exemplo:

```text
affiliate_id
offer_id
creator_name
partner_code
tracking_id
```

Esses parâmetros personalizados também ficam disponíveis em todo ecossistema da plataforma.

Podendo ser utilizados em:

<Badge color="purple">Links</Badge>

<Badge color="purple">Acionadores</Badge>

<Badge color="purple">Logs</Badge>

Isso torna o Trackup extremamente flexível.
