--- title: Plataformas de venda icon: cart description: Receba vendas, reembolsos e chargebacks por webhook e ligue cada venda ao anúncio de origem. ---

Configure pela sua IA. Conecte seu assistente pelo MCP e peça: "Conecte uma plataforma de venda ao projeto e me dê a URL do webhook."

A plataforma de venda é onde o cliente paga: um gateway de pagamento, uma plataforma de infoprodutos ou uma loja virtual. Integrada ao Trackup, ela envia um webhook a cada venda, reembolso ou chargeback, e o Trackup registra a conversão com a campanha que gerou o clique.

Como a atribuição funciona

  1. O visitante clica no botão de compra, que aponta para o link da oferta.
  2. O Trackup redireciona para o checkout adicionando o ID do clique e as UTMs na URL, no parâmetro que a plataforma aceita (em muitas é sck ou src; os parâmetros já vêm preenchidos para cada plataforma).
  3. A plataforma guarda esse ID no pedido e devolve no webhook.
  4. O Trackup encontra o clique, registra a conversão e dispara os acionadores de conversion.

Integrar uma plataforma

Vá em Integração › Plataformas de vendas e clique em Adicionar plataforma. Pesquise e selecione a sua no campo Plataforma.

Use um nome que identifique a conta, por exemplo Gateway · Online Store.

Os parâmetros do checkout vêm preenchidos para cada plataforma. Em Parâmetros avançados › Personalizar parâmetros você adiciona parâmetros extras à URL do checkout, como {request.sub1}. Use Inserir macro para ver a lista completa.

Salve e, na lista, copie a URL do webhook com Copiar URL. Se aparecer Configure um domínio, defina antes um domínio primário.

Na área de webhooks da plataforma de venda, cole a URL e habilite os eventos de pagamento confirmado, reembolso e chargeback. Algumas plataformas exigem um evento específico para trazer os itens da compra: confira a página de cada uma em Integrações.

Faça uma compra de teste pelo fluxo completo (anúncio, página, checkout, compra aprovada) e confira a venda em Logs › Conversões. Se aparecer o aviso Click ID ausente nesta conversão, a atribuição está incompleta: revise o link, o pixel e os parâmetros da plataforma.

A URL do webhook usa o domínio primário do projeto. Configure o domínio antes de integrar, para não precisar trocar a URL depois.

Macros do checkout

Os parâmetros aceitam valores fixos ou macros no formato {request.campo}:

MacroValor
{request.id}ID do clique (request ID). Obrigatório para atribuição.
{request.utmSource} … {request.utmContent}UTMs do clique.
{request.clickId}Click ID da plataforma de anúncios.
{request.sub1} … {request.sub8}Sub IDs.
{request.campaignId}, {request.adsetId}, {request.adId}IDs de campanha, conjunto e anúncio.
{request.visitorId}ID do visitante.
{request.country}, {request.city}, {request.state}Localização.
{request.device}, {request.browser}, {request.os}Dispositivo.

Há mais macros, como origem do tráfego, IDs da conta, do conjunto e do criativo, idioma e host. Use Inserir macro para ver todas.

Excluir uma plataforma

Só é possível excluir uma plataforma que não está em nenhum link, página de checkout ou teste A/B. Remova esses vínculos antes.
