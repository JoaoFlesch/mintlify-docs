# Requisições 📡

### Visualize, investigue e entenda cada acesso em nível técnico.

Toda visita que passa pela infraestrutura do TrackUp deixa rastros.

Cada clique, acesso de página, evento disparado, origem de tráfego, parâmetros recebidos e comunicação com plataformas externas fica registrado dentro do módulo de **Requisições**.

Esse módulo funciona como uma central completa de observabilidade, permitindo analisar exatamente o que aconteceu em cada acesso que passou pelo seu projeto.

Em outras palavras:

> Se algo aconteceu na sua operação, o TrackUp registrou.

# O que são Requisições?

Sempre que um visitante interage com qualquer parte da infraestrutura do TrackUp, o sistema gera um registro técnico completo daquela interação.

Exemplos:

```text
Clique em anúncio

Acesso em landing page

Carregamento de página

Redirecionamento

Início de checkout

Conversão

Disparo de eventos

Chamadas de API
```

Cada uma dessas ações gera uma requisição que fica armazenada para consulta posterior.

---

# O papel das Requisições dentro do ecossistema TrackUp

Até este ponto da jornada, o TrackUp já consegue:

- capturar cliques
- preservar parâmetros
- registrar eventos
- filtrar tráfego
- disparar pixels
- processar automações

O módulo de Requisições permite visualizar tudo isso acontecendo.

Fluxo:

```text
Usuário interage com operação
↓
TrackUp registra atividade
↓
Sistema coleta dados técnicos
↓
Informações ficam armazenadas
↓
Você pode investigar cada detalhe posteriormente
```

Nada acontece sem ser registrado.

# Visão geral do tráfego

A tela principal de Requisições mostra todos os acessos processados pelo seu projeto.

Cada linha representa uma interação registrada dentro da infraestrutura.

Você consegue acompanhar o comportamento do tráfego de forma cronológica.

Cada registro exibe informações essenciais sobre aquela visita.

Exemplo de dados exibidos:

```text
Domínio acessado

Página visitada

Localização geográfica

Evento executado

Dispositivo utilizado

Sistema operacional

Origem do tráfego

Data e horário
```

Isso permite acompanhar toda atividade da operação em tempo real ou historicamente.

# Sistema avançado de filtros 🔎

Grandes operações geram milhares de registros diariamente.

Por isso o módulo conta com um sistema avançado de filtros para facilitar análise.

Você pode segmentar as requisições por diversos critérios.

Atualmente é possível filtrar por:

```text
Período

Tipo de visitante

Host (domínio)

Path (URL acessada)

IP

Evento

Decisão do sistema

País

Dispositivo
```

Isso permite investigar exatamente o tipo de tráfego que você deseja analisar.

Exemplo:

```text
Mostrar apenas visitantes reais vindos do Instagram nos últimos 7 dias
```

Ou:

```text
Mostrar apenas acessos bloqueados de determinado país
```

O objetivo é facilitar investigações específicas.

# Investigando uma requisição específica

Cada linha da tabela representa uma visita individual.

Ao clicar em qualquer registro, o TrackUp abre uma visão completa daquele acesso.

Você passa a visualizar todos os dados técnicos e comerciais daquela interação.

Essa visão detalhada está dividida em diferentes camadas de análise.

---

# Aba Resumo 📋

A aba **Resumo** reúne todas as informações relacionadas àquele visitante específico.

Ela permite entender exatamente quem acessou sua operação e como essa visita aconteceu.

---

## Riscos e decisão do sistema

O TrackUp avalia diversos fatores técnicos durante a visita.

Aqui você consegue visualizar decisões tomadas automaticamente.

Exemplos:

```text
Bot identificado → Não

Desafio de segurança → Não

Decisão final → Permitir acesso
```

Isso ajuda a entender como o sistema interpretou aquele acesso.

---

## Identificação e localização

Cada visitante recebe um conjunto completo de dados técnicos.

Exemplo:

```text
Visitor ID único

IP do visitante

País

Cidade

Latitude e longitude

Fuso horário
```

Esses dados ajudam a investigar comportamento e origem do acesso.

---

## Informações do dispositivo

Também registramos detalhes técnicos sobre o ambiente utilizado pelo visitante.

Exemplo:

```text
Samsung Galaxy S23

Android 14

Instagram Browser

Mobile Device
```

Essas informações ajudam a entender contexto completo da visita.

---

## Dados de marketing e UTMs

Uma das áreas mais importantes para operações de tráfego pago.

O TrackUp captura automaticamente parâmetros de campanha recebidos durante o clique.

Exemplo:

```text
utm_source

utm_medium

utm_campaign

utm_content

fbclid

gclid

ttclid
```

Isso permite identificar exatamente qual campanha gerou aquele acesso.

Exemplo real:

```text
Instagram Reel → Criativo 03 → Campanha Escala Junho
```

Você consegue conectar cada visitante ao anúncio exato que originou a visita.

# Auditoria técnica com Logs ⚙️

Além do resumo da visita, você também pode analisar toda comunicação técnica gerada pelo sistema.

A aba **Logs** mostra exatamente como o TrackUp processou e enviou dados para integrações externas.

Essa área é essencial para validar se tudo está funcionando corretamente.

---

# Logs de disparo Server-Side

Sempre que o TrackUp envia eventos para plataformas externas, toda comunicação fica registrada.

Exemplo:

```text
Envio de evento para API do Facebook

Envio para Google Ads

Chamadas internas do sistema

Eventos processados por acionadores
```

Isso permite auditar exatamente o que aconteceu nos bastidores.

---

# Visualizando o Request enviado

O sistema exibe o payload completo enviado para a plataforma externa.

Exemplo simplificado:

```json
{
  "event_name": "PageView",
  "event_time": 1781458231,
  "external_id": "visitor_7a92f",
  "ip_address": "***",
  "fbc": "fb.1.23918293"
}
```

Aqui você consegue visualizar exatamente quais dados foram enviados.

---

# Visualizando a resposta da API

Depois do envio, o sistema também registra a resposta retornada pela plataforma.

Exemplo:

```json
{
  "events_received": 1
}
```

Status:

```text
HTTP 200
```

Isso confirma que a integração recebeu o evento corretamente.

Exemplo prático:

```text
TrackUp enviou evento PageView
↓

Meta API recebeu o evento

↓

Resposta HTTP 200

↓

Evento contabilizado com sucesso
```

Você consegue auditar toda comunicação em nível técnico.

# Investigação completa da jornada

O módulo de Requisições funciona como uma ferramenta de investigação.

Você consegue seguir o caminho completo de cada interação.

Exemplo:

```text
Usuário viu anúncio no Instagram
↓
Clicou no anúncio
↓
TrackUp registrou ad_click
↓
Visitou landing page
↓
Sistema registrou page_view
↓
UTMs foram preservadas
↓
Acionador enviou evento para Meta
↓
Meta confirmou recebimento do evento
```

Tudo fica registrado.

Tudo pode ser auditado.

# Por que isso é importante?

Em operações digitais, pequenos erros técnicos podem gerar grandes prejuízos.

Exemplos:

- Pixel não disparando
- Eventos sendo rejeitados
- Parâmetros sendo perdidos
- Conversões não atribuídas
- Campanhas recebendo dados incorretos

Com o módulo de Requisições você consegue identificar esses problemas rapidamente.
