--- title: Pixels icon: pixel description: Conecte Meta, Google Ads, TikTok e Kwai para enviar os eventos do funil pelo servidor. ---

Um pixel guarda as credenciais da API de conversões de uma plataforma de anúncios. Os acionadores usam o pixel para enviar eventos como page_view, start_checkout e conversion.

Adicionar um pixel

Vá em Integração › Pixels e clique em Adicionar pixel.

Dê um nome que identifique a conta, como Meta · BM Principal, e preencha os campos da plataforma (veja abaixo).

Em Meta, TikTok e Kwai o Trackup cria automaticamente os acionadores Pageview, Start checkout e Conversão. No Google Ads você cria os acionadores com a conversion label de cada etapa.

Campos por plataforma

CampoOnde encontrar
Pixel IDGerenciador de Eventos › Fontes de dados › seu pixel.
Access TokenGerenciador de Eventos › Configurações › API de Conversões › Gerar token de acesso.
Test Event Code opcionalGerenciador de Eventos › Testar eventos.

Com o Test Event Code preenchido, os eventos vão só para Test Events e não contam nas campanhas. O pixel aparece marcado como modo teste na lista. Apague o código para ir para produção.
CampoOnde encontrar
Conversion IDGoogle Ads › Metas › Conversões › Resumo › ação de conversão › Configuração da tag. É o número depois de AW-; o prefixo é opcional.
Moeda padrão opcionalCódigo ISO, como BRL ou USD.
Valor padrão opcionalValor enviado quando o acionador não define um.

A conversion label fica em cada acionador, no campo de evento. Crie uma ação de conversão no Google Ads para cada etapa que você quer otimizar.
CampoOnde encontrar
Pixel CodeTikTok Ads Manager › Ferramentas › Eventos › Web.
Access TokenConfigurações do pixel › Gerar token de acesso.
CampoOnde encontrar
Pixel ID e Access TokenKwai for Business › Ferramentas › Pixel.
Test Event CodeObrigatório no Kwai. Valida eventos de teste quando não há click_id na URL.

Servidor ou navegador

Por padrão os eventos vão pelo servidor (API de Conversões), o que evita perdas por bloqueadores de anúncio. No acionador você também pode ativar o disparo pelo navegador, disponível só para Meta e TikTok.

PlataformaServidorNavegador
MetaSimSim
TikTokSimSim
Google AdsSimNão
KwaiSimNão

Desativar um pixel

Edite o pixel e desligue Ativo. Os acionadores param de enviar eventos para ele, sem perder a configuração.
