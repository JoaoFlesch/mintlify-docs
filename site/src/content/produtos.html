--- title: Produtos icon: package description: Veja os produtos e ofertas que você vende, registrados automaticamente a partir das vendas. ---

Configure pela sua IA. Conecte seu assistente pelo MCP e peça: "Liste os produtos vendidos no projeto Online Store e a data da primeira venda de cada um."

A tela Produtos lista os produtos vendidos nas suas plataformas de venda. Você não precisa cadastrá-los: cada produto aparece quando a primeira venda dele chega pelo webhook.

  1. Plataforma de venda: filtra a lista por plataforma. Por padrão aparecem todas.
  2. Produto: cada linha mostra o nome e o ID do produto na plataforma, com o número de Ofertas da plataforma. Clique na seta para expandir e ver as ofertas (planos ou preços diferentes do mesmo produto). Cada oferta aparece pelo nome e pelo ID de preço que a plataforma enviou.
  3. Primeira venda: mostra quando o produto apareceu pela primeira vez.

Se o mesmo produto aparecer em duas linhas, a plataforma enviou o produto com IDs diferentes em vendas diferentes. O Trackup mostra cada ID separadamente.

A tela Produtos lista o que a plataforma de venda vendeu. Para criar o link de checkout que você usa nas páginas, veja Ofertas.
