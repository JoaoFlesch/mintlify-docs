# O que são Conversões?

Sempre que uma venda acontece em uma plataforma integrada ao Trackup, recebemos automaticamente os dados daquela transação.

Normalmente isso acontece através das integrações com plataformas de venda e gateways de pagamento.

Exemplos:

```text
Stripe
Hotmart
Upag
```

Assim que o pagamento é processado, o Trackup recebe as informações da venda e inicia o processo de atribuição.

---

# Cada venda é automaticamente atribuída

Quando uma conversão chega ao Trackup, não é apenas registrado o pagamento.

Ele reconstrói toda origem daquela venda.

O objetivo é responder:

```text
Quem comprou?

Qual anúncio trouxe essa pessoa?

Qual campanha originou a venda?

Qual criativo gerou a conversão?
```

Toda venda passa por um processo automático de atribuição.

Fluxo:

```text
Webhook recebido
↓
Trackup identifica Visitor
↓
Trackup localiza Click ID
↓
UTMs são associadas
↓
Campanha é identificada
↓
Venda recebe atribuição completa
```

---

# Investigando uma venda específica

Ao clicar em qualquer conversão registrada, o Trackup exibe uma análise completa daquela venda.

Essa visão detalhada mostra exatamente de onde aquele dinheiro veio.

---

# Dados recebidos do gateway

A primeira seção exibe as informações enviadas pela plataforma de pagamento.

Esses são os dados brutos recebidos via integração.

Exemplo:

```text
Transaction ID
Valor da venda
Moeda
Valor líquido
Taxas
Dados enviados pelo webhook
```

Exemplo:

```text
Gateway → Upag
Amount → R$17,90
Currency → BRL
Transaction ID → 87362819
```

Isso permite validar a integridade dos dados.

---

# Associação com o visitante

Toda conversão é conectada automaticamente ao Visitante correspondente.

Isso significa que a venda fica permanentemente associada ao perfil daquele usuário.

Exemplo:

```text
Visitor ID
IP do comprador
Link utilizado
Histórico anterior de navegação
```

Isso conecta faturamento com comportamento.

Agora você sabe exatamente quem comprou.

---

# Atribuição de marketing precisa

Essa é uma das partes mais importantes do módulo.

O Trackup consegue identificar exatamente qual estrutura de marketing gerou a venda.

Dados armazenados:

```text
utm_source
utm_medium
utm_campaign
utm_content
utm_term
Click ID
```

Exemplo real:

```text
utm_source → Facebook
utm_term → Instagram Feed
Campaign → CAMP TESTE Trackup BID COMPRA VIDEO
```

Agora você consegue identificar qual campanha foi responsável pelo faturamento.

# Integração com plataformas de anúncios

Além das UTMs, o Trackup também preserva os identificadores técnicos responsáveis pela atribuição.

Exemplo:

```text
Ad Account ID
Campaign ID
Ad Set ID
Ad ID
```

Exemplo:

```text
Ad Set ID → 120248366188090742
```

Isso permite localizar rapidamente a estrutura exata dentro da plataforma de anúncios.

Na prática:

```text
Você descobre exatamente qual anúncio gerou a venda
```

---

# Diagnóstico inteligente de problemas

Nem toda conversão chega com dados perfeitos.

Quando existe algum problema de rastreamento, o Trackup detecta automaticamente inconsistências.

O Trackup alerta quando informações críticas estão ausentes.

Exemplo comum:

```text
Venda chegou
↓
Pagamento confirmado
↓
Mas Click ID não foi encontrado
```

Nesse cenário a venda existe.

Mas a atribuição fica comprometida.

---

# Alertas automáticos

Quando o Trackup detecta problemas, um alerta visual é exibido.

Exemplo:

```text
⚠️ Click ID ausente nesta conversão
```

Mensagem:

```text
Esta conversão não registrou um Click ID.
Isso normalmente indica problemas na configuração dos Links, parâmetros ou integração com a plataforma de vendas.
```

Esse alerta ajuda a identificar falhas rapidamente.

# Por que o Click ID é tão importante?

O Click ID funciona como o elo entre o clique inicial e a venda final.

Exemplo:

```text
Fonte de tráfego gera clique
↓
Usuário acessa Link Trackup
↓
Trackup preserva Click ID
↓
Usuário compra
↓
Conversão é enviada de volta para Fonte de tráfego
```

Sem o Click ID:

```text
A venda existe

Mas a plataforma de anúncios não consegue identificar qual clique gerou a conversão
```

Resultado:

```text
Campanhas perdem qualidade de otimização
```
