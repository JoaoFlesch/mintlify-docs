Uma página é qualquer endereço do seu domínio no Trackup: uma landing page, uma pré-venda, uma VSL ou o redirecionamento para um checkout. Toda página nasce com um link próprio e já é rastreada, sem instalar nada.

Finalidade

FinalidadeOnde apareceUso
LandingMenu PáginasPáginas que recebem o tráfego do anúncio. Geram page_view.
CheckoutMenu OfertasLevam ao checkout da plataforma de venda. Geram start_checkout. Veja Ofertas.

Quatro formas de criar

Editor visual com blocos e templates. Sem código. Envie um .html ou um .zip com os arquivos da página. Capture uma página que já está no ar e edite os arquivos. Mantenha a página onde está e passe o tráfego pelo Trackup.

Criar uma página

No menu lateral, clique em Páginas e em Adicionar página.

Selecione Redirect, Builder, Upload HTML ou Clonar URL e preencha o formulário.

O Caminho é o endereço da página no domínio. Use / para a raiz (seudominio.com) ou algo como /oferta. Em branco, o Trackup gera a partir do nome. Letras, números, -, ., _, ~ e / são aceitos.

Rascunho e publicada

Páginas novas são publicadas na criação. Depois, toda alteração de arquivo deixa a página em Rascunho até você publicar de novo. Enquanto isso, quem acessa o link continua vendo a versão publicada.

Deletar uma página quebra todos os anúncios e testes A/B que apontam para ela. Confira antes se ela não está em uso.

Boas práticas

  • Use nomes que digam a função: Landing Principal, VSL Produto X, Pré-checkout.
  • Mantenha um projeto por produto ou cliente, para não misturar páginas e relatórios.
  • Os botões de compra devem apontar para o link da oferta, nunca para o checkout original.
