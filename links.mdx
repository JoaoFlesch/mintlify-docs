É através deles que a plataforma identifica um novo visitante, inicia o rastreamento da sessão, preserva os parâmetros recebidos da origem do tráfego e acompanha toda a jornada até a conversão.

Independentemente da origem do acesso, todo visitante deve entrar no seu funil preferencialmente por um Link criado dentro do Trackup para que os dados possam ser registrados corretamente.

> Os Links são a base do sistema de rastreamento. Sem eles, o TrackUp não consegue acompanhar a jornada completa do visitante.

# Tipos de Links

O Trackup possui diferentes tipos de Links, cada um desenvolvido para um momento específico da jornada do usuário.

<Card title="Link Genérico" icon="link-2">
  O tipo mais flexível de link dentro da plataforma.

  Os Links Genéricos funcionam como links de rastreamento universais.

  Eles podem ser utilizados em praticamente qualquer cenário onde você deseja apenas enviar tráfego preservando dados da jornada.

  Ideal para:

  - Redirecionamento dentro do seu Funil
  - Links em bio
  - Operações orgânicas

  Eles não dependem de parâmetros específicos de plataformas de mídia.

  <Note>
    [Antes de criar um Link de Anúncio , você precisa cadastrar uma Página.](/entendendo-paginas)
  </Note>

  Todo acesso de um link genérico dispara um evento de <Badge color="purple">page_view</Badge>
</Card>

<Card title="Link de Anúncio" icon="megaphone">
  Os Links de Anúncio foram desenvolvidos especificamente para campanhas de mídia paga.

  Esse tipo de link identifica e processa parâmetros enviados pelas plataformas de anúncios e é personalizado para cada fonte de tráfego

  Essas informações ajudam o Trackup a entender exatamente de onde aquele visitante veio e atribuir cada evento com o máximo de detalhes em uma futura conversão

  <Note>
    [Antes de criar um Link de Anúncio , você precisa cadastrar uma Página.](/entendendo-paginas)
  </Note>

  Todo acesso de um Link de Anúncio dispara um evento de <Badge color="purple">ad_click</Badge>
</Card>

<Card title="Link de Checkout" icon="shopping-cart">
  O Link de Checkout representa o último passo da jornada do usuário antes da conversão.

  Esse tipo de link conecta o visitante à Oferta previamente cadastrada dentro do projeto.

  Ele é responsável por garantir que todos os dados coletados durante a navegação continuem sendo preservados até o momento final da compra.

  <Note>
    [Antes de criar um Link de Checkout , você precisa cadastrar uma Oferta.](/ofertas)
  </Note>

  Todo acesso de um Link de Checkout dispara um evento de<Badge color="purple">start_checkout</Badge>
</Card>

# Ver URL

Clicando em Ver URLo Trackup disponibiliza automaticamente todas as informações necessárias para utilizá-lo nas suas campanhas.

<AccordionGroup>
  <Accordion title="1. URL Base">
    A **URL Base** é o endereço principal do Link, sem nenhum parâmetro adicional.

    Ela é utilizada como ponto de partida para a montagem da URL final e pode ser utilizada em integrações ou configurações personalizadas.
  </Accordion>

  <Accordion title="2. Parâmetros (Query String)">
    Nesta seção são exibidos todos os parâmetros configurados para a **Fonte de Tráfego** selecionada.

    Esses parâmetros serão substituídos automaticamente pela plataforma de anúncios no momento do clique.
  </Accordion>

  <Accordion title="3. Parâmetros do Filtro">
    Se o Link possuir **Filtros** configurados, o Trackup exibirá automaticamente os parâmetros necessários para liberar o acesso.

    Esses parâmetros são adicionados à URL final e garantem que as regras de filtragem sejam executadas corretamente.

    <Warning>
      Não remova esses parâmetros caso o Link utilize Filtros, pois isso poderá impedir o funcionamento esperado da página.
    </Warning>
  </Accordion>

  <Accordion title="4.URL Final">
    A **URL Final** já combina automaticamente:

    - URL Base;
    - Parâmetros da Fonte de Tráfego;
    - Parâmetros dos Filtros (quando existirem).

    Na maioria dos casos, esta é a URL que deve ser utilizada diretamente nas campanhas, pois já contém toda a configuração necessária para o rastreamento completo.
  </Accordion>

  <Accordion title="5. QR Code">
    O Trackup também gera automaticamente um **QR Code** apontando para o mesmo Link.

    Ele pode ser utilizado em materiais impressos, apresentações, eventos ou qualquer outro canal offline.

    É possível:

    - Copiar a URL do QR Code.
    - Abrir a imagem em uma nova aba.
    - Compartilhar o QR Code diretamente.
  </Accordion>
</AccordionGroup>

# Teste A/B

O **Teste A/B** permite distribuir automaticamente os visitantes entre duas ou mais páginas utilizando um único Link.

Essa funcionalidade é ideal para comparar diferentes versões de uma Landing Page, VSL, Checkout ou qualquer outra etapa do funil, identificando qual delas apresenta melhor desempenho.

Toda a distribuição é realizada automaticamente pelo Trackup, enquanto o rastreamento da jornada permanece intacto.

Essa funcionalidade é ideal para comparar variações de Landing Pages, VSLs, ofertas ou checkouts sem precisar alterar seus anúncios.

Você define a porcentagem de distribuição e o TrackUp envia os visitantes automaticamente.

# Preservação de parâmetros

Uma das funções mais importantes dos Links do Trackup é preservar informações importantes durante toda jornada do visitante.

Quando um usuário chega através de uma campanha, diversos parâmetros acompanham esse clique.

```text
utm_source=facebook
utm_medium=cpc
utm_campaign=escala_julho
fbclid=xxxxxxxx
```

Se esses parâmetros forem perdidos durante a navegação, a atribuição da conversão pode quebrar.

O Trackup garante que esses dados continuem existindo durante toda jornada, tendo em vista que tudo isso fica salvo em cada [requisição](/requisiocoes) e atribuído ao [visitante](/visitantes)

# O que é o Click ID do Trackup?

Sempre que alguém acessa um Link criado dentro da plataforma, o Trackup gera automaticamente um identificador único interno.

Chamamos isso de Click ID.

Esse identificador acompanha toda jornada do visitante.

Ele conecta todos os eventos relacionados àquele usuário.

<Badge color="purple">Clique inicial</Badge>   <Badge color="purple">Page View</Badge>   <Badge color="purple">Navegação</Badge>   <Badge color="purple">Checkout</Badge>   <Badge color="purple">Conversão</Badge>

Tudo fica associado ao mesmo identificador interno.
