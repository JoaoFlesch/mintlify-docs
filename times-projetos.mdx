### Entenda como organizar sua operação dentro do TrackUp.

Toda a estrutura do TrackUp foi criada para permitir que você organize sua operação de forma escalável, colaborativa e bem estruturada.

Antes de começar a criar páginas, campanhas ou links, é importante entender como a plataforma organiza seus recursos.

No TrackUp, tudo funciona a partir de uma estrutura central composta por:

- Times
- Projetos
- Membros

Essa arquitetura foi pensada para permitir que múltiplas pessoas trabalhem na mesma operação de forma organizada.

# Como funciona a estrutura do TrackUp

Toda organização dentro da plataforma segue esta lógica:

```text
```

```text
Time
 ├── Membros
 │      ├── Administrador
 │      ├── Operador
 │      └── Analista
 │
 └── Projetos
        ├── Projeto A
        ├── Projeto B
        └── Projeto C
```

Dentro de cada Projeto ficam todos os recursos operacionais.

Exemplo:

```text
```

```text
Projeto

├── Campaign Manager
├── Pages
├── Links
├── Offers
├── Event Triggers
├── Logs
├── Integrations
└── Traffic Protection
```

# O que é um Time?

O Time representa o ambiente principal da sua operação dentro do TrackUp.

Pense nele como sua empresa, sua operação ou seu workspace principal.

É dentro do Time que você centraliza tudo que faz parte daquela estrutura.

Cada Time possui:

- \
  Seus próprios membros\
- \
  Seus próprios projetos\
- \
  Sua assinatura ativa\
- \
  Seus limites de uso\
- \
  Suas configurações gerais\

Em resumo:

> O Time é o ambiente principal que organiza toda sua operação.

---

### Exemplo prático

Se você possui uma agência:

```text
```

```text
Time → Atlas Media
```

Se você trabalha como afiliado:

```text
```

```text
Time → João Performance
```

Se você possui múltiplas operações:

```text
```

```text
Time → Finance Group
```

Cada Time funciona como uma estrutura independente.

# O que são Membros?

Membros são os usuários que possuem acesso a um determinado Time.

Todo membro pertence ao Time.

Isso significa que ele poderá colaborar em toda estrutura existente dentro daquele ambiente.

Exemplo:

Dentro de um Time você pode adicionar:

- \
  Sócios\
- \
  Gestores de tráfego\
- \
  Designers\
- \
  Desenvolvedores\
- \
  Analistas\
- \
  Equipe operacional\

Esses membros compartilham acesso ao mesmo ambiente.

---

### Exemplo visual

```text
```

```text
Time → Atlas Media

Membros

• João → Administrador  
• Pedro → Gestor de Tráfego  
• Lucas → Designer  
• Ana → Analista
```

Todos pertencem ao mesmo Time.

---

# Como funcionam permissões?

Cada membro pode possuir diferentes níveis de acesso dentro do Time.

As permissões permitem controlar o que cada usuário pode visualizar ou alterar.

Alguns exemplos:

### Administrador

Pode:

- \
  Criar projetos\
- \
  Convidar membros\
- \
  Alterar configurações\
- \
  Gerenciar domínio\
- \
  Gerenciar integrações\

---

### Operador

Pode:

- \
  Criar páginas\
- \
  Criar links\
- \
  Criar ofertas\
- \
  Gerenciar campanhas\

---

### Analista

Pode:

- \
  Visualizar relatórios\
- \
  Acompanhar métricas\
- \
  Visualizar logs\

---

### Desenvolvedor

Pode:

- \
  Trabalhar com integrações\
- \
  Configurar webhooks\
- \
  Trabalhar com API\

_(As permissões continuarão evoluindo conforme novas funcionalidades forem adicionadas.)_

# O que é um Projeto?

Projetos são operações individuais criadas dentro de um Time.

Cada Projeto representa uma estrutura independente dentro daquele ambiente.

Recomendamos utilizar um Projeto para cada:

- \
  Produto\
- \
  Funil\
- \
  Cliente\
- \
  Oferta principal\
- \
  Operação específica\

O objetivo é manter cada operação organizada separadamente.

---

### Exemplo

```text
```

```text
Time → Atlas Media

Projetos

Projeto 1 → Produto Financeiro  
Projeto 2 → Produto Nutra  
Projeto 3 → Produto SaaS
```

Ou:

```text
```

```text
Time → Agência Scale

Projetos

Projeto 1 → Cliente Imobiliária  
Projeto 2 → Cliente Clínica  
Projeto 3 → Cliente E-commerce
```

# O que fica dentro de um Projeto?

Todo recurso operacional do TrackUp fica vinculado a um Projeto específico.

Dentro de cada Projeto você pode gerenciar:

### Campaign Manager

Campanhas conectadas e sincronizadas.

### Pages

Landing pages hospedadas.

### Smart Links

Links de rastreamento e distribuição.

### Offers

Checkouts conectados.

### Event Triggers

Eventos enviados para pixels.

### Traffic Protection

Regras de proteção de tráfego.

### Analytics & Logs

Dados detalhados dos visitantes.

### Integrations

Conexões externas da operação.

---

Exemplo:

```text
```

```text
Projeto → Produto Financeiro

├── Campanhas
├── Landing Pages
├── Links
├── Offers
├── Logs
├── Eventos
└── Integrações
```

# Como organizar corretamente sua estrutura

A organização correta depende do seu modelo de operação.

---

### Se você é afiliado

Crie um Projeto para cada oferta.

```text
```

```text
Time → João Performance

Projeto 1 → Produto Financeiro  
Projeto 2 → Produto Nutra  
Projeto 3 → Produto SaaS
```

---

### Se você possui agência

Crie um Projeto para cada cliente.

```text
```

```text
Time → Atlas Agency

Projeto 1 → Cliente A  
Projeto 2 → Cliente B  
Projeto 3 → Cliente C
```

---

### Se você é infoprodutor

Crie um Projeto para cada funil.

```text
```

```text
Time → Minha Operação

Projeto 1 → Frontend  
Projeto 2 → Upsell  
Projeto 3 → Webinar
```

# Limites por plano

Cada Time possui limites definidos pelo plano contratado.

Esses limites podem incluir:

- \
  Quantidade máxima de projetos\
- \
  Quantidade máxima de membros\
- \
  Recursos disponíveis\
- \
  Limites operacionais\

Os limites variam de acordo com sua assinatura ativa.
