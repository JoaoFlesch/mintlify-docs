Os diagramas mostram como as peças do Trackup se ligam. Cada etapa é um cartão com ícone, título e uma linha de apoio. Três formatos cobrem os casos da documentação.

Fluxo em linha

Para sequências, como o caminho de uma venda.

URL da campanha com UTMs Requisição registrada e filtrada Evento page_view Link do checkout com o Click ID Webhook liga a venda ao clique

Fluxo com ramificação

Para decisões, como o filtro ou um teste A/B.

Recebe o acesso Aplica as regras Vai para a página real Vai para a página segura Divide o tráfego 50% dos visitantes 50% dos visitantes Sem tráfego Compare conversões

Fluxo vertical

Para listas curtas de dependências, ou quando o texto das etapas é longo.

Assinatura, membros e chaves de API Um por produto, oferta ou cliente Subdomínio do projeto

Como escrever

URL da campanha Página real Página segura

tone aceita ok, stop e brand. Os ícones vêm da lista interna da documentação. No celular o fluxo vira uma coluna com setas para baixo.
