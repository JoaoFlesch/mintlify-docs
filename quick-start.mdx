# Configure sua primeira operação

Se esta é sua primeira vez utilizando o Trackup, este guia mostra o caminho mais rápido para configurar sua infraestrutura completa e começar a rastrear campanhas, usuários e conversões corretamente.

Ao final deste processo você terá uma operação pronta para receber tráfego e atribuir vendas de ponta a ponta.

Fluxo padrão:

```text
Anúncio → Página → Checkout → Conversão
```

Todo o ecossistema do Trackup gira em torno dessa estrutura.

# Fluxo completo da operação

```text
Campanha
↓
Link de anúncio
↓
Landing Page
↓
Botão de compra
↓
Link de checkout
↓
Checkout
↓
Webhook recebido
↓
Conversão registrada
↓
Evento enviado para pixel
↓
Dados aparecem nos relatórios
```

Essa é a arquitetura padrão utilizada pela maioria das operações dentro do Trackup.

Caso você tenha uma operação diferente ou ficou com alguma dúvida, entre em contato com nosso suporte.
