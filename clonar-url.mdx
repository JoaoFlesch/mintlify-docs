Nem sempre você quer começar uma página do zero.

Muitas vezes você encontra uma página que deseja utilizar como base, já possui estruturas espalhadas em outras hospedagens ou simplesmente precisa replicar rapidamente uma página existente.

Com o clonador de url, você informa uma URL pública, o Trackup replica automaticamente a estrutura da página e disponibiliza todos os arquivos para edição dentro da plataforma.

# Como funciona o Clonar URL?

O processo foi criado para ser extremamente simples.

Você escolhe uma página existente na internet.

Informa a URL dentro do Trackup.

O Trackup processa automaticamente a estrutura da página e replica os arquivos para dentro do seu projeto.

Fluxo:

```text
Inserir URL
↓
Trackup analisa a página
↓
Sistema replica a estrutura
↓
Arquivos são hospedados internamente
↓
Página fica disponível para edição
```

Sem precisar copiar arquivos manualmente.

Sem precisar reconstruir páginas do zero.

# O que acontece após o clone?

Após concluir o processo, a página deixa de depender do endereço original.

Toda estrutura passa a existir dentro do próprio Trackup.

Isso significa que você passa a ter controle total sobre os arquivos importados.

```text
[IMAGEM RECOMENDADA] FAZER UM NEGOCIO BONITO DESSE FLUXO

Trackup cria uma cópia local completa

HTML importado

CSS importado

JavaScript importado

Assets importados

Arquivos disponíveis no projeto
```

---

# Edição completa após a clonagem

Depois que o clone é concluído, todos os arquivos ficam disponíveis dentro do gerenciador interno do Trackup, como se tivesse sido feito um [Upload HTML](/upload-html).

Você poderá visualizar toda estrutura importada.

# Editor de código interno 

Assim como no [Upload HTML](/upload-html), páginas clonadas podem ser editadas diretamente dentro do Trackup.

Você pode abrir qualquer arquivo importado e modificar o código manualmente.

Exemplo de arquivos editáveis.

- HTML
- CSS
- JavaScript
- JSON
- Assets da página
- Arquivos de configuração

Tudo diretamente no editor interno da plataforma.

Sem necessidade de baixar arquivos localmente.

Sem depender de softwares externos.
