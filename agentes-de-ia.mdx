Agentes de IA, assistentes com acesso a ferramentas e automações com LLM usam o Trackup pela mesma API externa que qualquer integração: uma **Chave de API do Time**, enviada no header `X-Api-Key`.

<Info>
  Usa Claude, ChatGPT, Cursor ou VS Code? O jeito mais rápido é o [servidor MCP do Trackup](/conectar-mcp): sem código e com a configuração guiada.
</Info>

Você decide o que o agente enxerga e o que ele pode alterar. Tudo que ele fizer fica registrado.

<Badge color="purple">Registrar vendas</Badge> <Badge color="purple">Consultar dados</Badge> <Badge color="purple">Operar campanhas</Badge> <Badge color="purple">Configurar projetos</Badge>

# O que um agente pode fazer

| Objetivo | Rotas | Permissões |
| :- | :- | :- |
| Registrar conversões, reembolsos e chargebacks vindos de um CRM, ERP ou checkout | `POST /conversions`, `/refunds`, `/chargebacks` | `conversion.create` |
| Criar visitantes e eventos | `POST /visitors`, `/requests` | `visitor.create`, `request.create` |
| Ler métricas e listas | `GET /projects/:id/analytics/overview`, `/conversions`, `/visitors`, `/requests` | `analytics.read`, `conversion.list`, `visitor.list`, `request.list` |
| Acompanhar e ajustar campanhas Meta | `GET /ads-manager/:projectId/summary`, `/table`; `PATCH .../entities/:entityId/status`, `/budget` | `ads-manager.read`, `ads-manager.update` |
| Configurar o projeto | pixels, domínios, links, páginas, fontes de tráfego, plataformas de venda | `pixel.*`, `domain.*`, `link.*`, `page.*`, `traffic-source.*`, `sales-platform.*` |

O agente nunca acessa cobrança, membros, gestão de chaves, exclusão de projeto, conexões OAuth (Meta, Nuvemshop) nem os endpoints de IA do painel. Essas rotas respondem `403` para qualquer chave.

<Tip>
  A lista completa de rotas, corpos e permissões está em [Referência da API](/api-reference/projects/list-projects).
</Tip>

---

# Como o acesso funciona

Cada chave pertence ao Time e carrega três limites:

1. **Permissões** — o agente só executa as rotas cujas permissões a chave tem.
2. **Projetos** — a chave acessa todos os projetos do Time ou apenas os que você listar. Projetos fora da lista respondem `404`.
3. **Expiração** — opcional. Depois da data, a chave responde `403`.

<Note>
  A chave age em nome de quem a criou. Se essa pessoa sair do Time ou perder uma permissão, o agente perde o acesso junto. Crie chaves de agentes a partir de uma conta estável da operação.
</Note>

Toda requisição feita pelo agente fica no histórico da chave: método, caminho, status, duração e os corpos de requisição e resposta com segredos mascarados.

# Contexto para o agente

Cole este bloco nas instruções do agente e substitua a chave pela variável do seu cofre.

```text
Você opera o Trackup pela API REST.

Base: https://api.trackup.me/v1
Autenticação: header X-Api-Key. Não envie X-Team-Id.
Corpo e respostas em JSON. Listagens retornam { "data": [...], "count": n } e aceitam page e limit.

Projetos: GET /projects lista os projetos acessíveis; use o id em /projects/:id/...
Ingestão (POST /visitors, /conversions, /refunds, /chargebacks, /requests): envie projectId no corpo,
exceto quando a chave estiver restrita a um único projeto.
Conversões: value é obrigatório. Envie transactionId para evitar duplicidade; 409 significa que a
transação já foi registrada com esse status, não tente de novo.

Erros: 400 projectId ausente; 401 chave inválida; 403 sem permissão, chave revogada/expirada ou rota
indisponível; 404 projeto fora do escopo; 409 conversão duplicada; 422 corpo inválido.

Nunca tente: cobrança, membros, chaves de API, exclusão de projeto, OAuth ou /ai.
Referência completa (OpenAPI): https://api.trackup.me/openapi.json
```

# Boas práticas

- **Uma chave por agente.** Facilita revogar, auditar e entender o histórico.
- **Projetos restritos.** Um agente de um cliente não deve enxergar os outros.
- **Expiração em testes.** Chaves de experimento morrem sozinhas.
- **Aprovação humana para ações destrutivas.** Pausar campanhas, alterar orçamentos e apagar recursos merecem confirmação de uma pessoa antes da chamada.
- **Revogue ao desligar o agente.** A chave para de funcionar na hora e o histórico continua disponível.
- **Trate `409` e `4xx` como resposta, não como falha.** O agente deve ler a mensagem e ajustar a chamada em vez de repetir.
