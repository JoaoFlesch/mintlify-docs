Todas as rotas desta página aceitam autenticação via API Key. O corpo das requisições é JSON.

## URL base

**Produção:** `https://dash-api.trackup.me/v1`

Monte a URL completa concatenando o endpoint ao base. Exemplo: `https://dash-api.trackup.me/v1/visitors`.

## Autenticação

Envie a chave no header `X-Api-Key` em cada requisição. A chave pertence ao time e é criada em **Configurações → Chaves de API**.

| Status | Condição |
| --- | --- |
| `401` | Header ausente ou chave inválida |
| `403` | Chave revogada, expirada, sem a permissão exigida pela rota, ou rota indisponível por chave |

Não é necessário enviar `X-Team-Id`: o time é o da chave. Se o header for enviado com outro time, a resposta é `403`.

## Permissões

Cada chave recebe uma lista de permissões no formato `recurso.acao` (por exemplo `pixel.create`, `domain.list`). A rota só é executada se a chave tiver a permissão exigida **e** o usuário que criou a chave ainda tiver essa permissão no time. As permissões de ingestão (`visitor.create`, `conversion.create`, `request.create`) são exclusivas de chaves: qualquer membro pode concedê-las e elas não são verificadas no criador. Se o criador deixar o time, a chave passa a responder `403`.

Permissões disponíveis para chaves: todas as de recursos de projeto (`project`, `domain`, `pixel`, `trigger`, `page`, `link`, `url`, `traffic-source`, `sales-platform`, `firewall-rule`, `ads-manager`, `analytics`, `visitor`, `conversion`, `request`, `request-log`, `asset`) mais as de ingestão `visitor.create`, `conversion.create` e `request.create`, que só existem em chaves. Não existem por chave: time, membros, assinatura, faturas, formas de pagamento, gestão de chaves, exclusão de projeto, OAuth (Nuvemshop, Meta) e os endpoints de IA.

## Escopo de projetos

A chave pode ser global (acessa todos os projetos do time) ou restrita a uma lista de projetos. Projetos fora da lista respondem `404`.

Nas rotas de ingestão (`/visitors`, `/conversions`, `/refunds`, `/chargebacks`, `/requests`) o projeto é definido assim:

| Chave | Campo `projectId` no corpo |
| --- | --- |
| Restrita a exatamente um projeto | Opcional (padrão: esse projeto) |
| Global ou restrita a vários projetos | Obrigatório (`400` se ausente) |

## Rotas de gestão

As mesmas rotas usadas pelo painel ficam disponíveis por chave, com a permissão indicada. `:id` é o ID do projeto.

| Método | Endpoint | Permissão |
| --- | --- | --- |
| `GET` | `/projects` | `project.list` (lista só os projetos acessíveis pela chave) |
| `POST` | `/projects` | `project.create` |
| `GET` | `/projects/:id` | `project.read` |
| `PUT` | `/projects/:id` | `project.update` |
| `POST` | `/projects/:id/publish` | `project.update` |
| `GET` `POST` | `/projects/:id/domains` | `domain.list` / `domain.create` |
| `GET` `PUT` `DELETE` | `/projects/:id/domains/:domainId` | `domain.read` / `domain.update` / `domain.delete` |
| `GET` `POST` | `/projects/:id/pixels` | `pixel.list` / `pixel.create` |
| `GET` `PUT` `DELETE` | `/projects/:id/pixels/:pixelId` | `pixel.read` / `pixel.update` / `pixel.delete` |
| `GET` `POST` | `/projects/:id/triggers` | `trigger.list` / `trigger.create` |
| `GET` `POST` | `/projects/:id/pages` | `page.list` / `page.create` |
| `GET` `POST` | `/projects/:id/links` | `link.list` / `link.create` |
| `GET` `POST` | `/projects/:id/traffic-sources` | `traffic-source.list` / `traffic-source.create` |
| `GET` `POST` | `/projects/:id/sales-platforms` | `sales-platform.list` / `sales-platform.create` |
| `GET` `POST` | `/projects/:id/firewall-rules` | `firewall-rule.read` / `firewall-rule.create` |
| `GET` | `/projects/:id/visitors` | `visitor.list` |
| `GET` | `/projects/:id/conversions` | `conversion.list` |
| `GET` | `/projects/:id/requests` | `request.list` |
| `GET` | `/projects/:id/analytics/overview` | `analytics.read` (os demais relatórios de analytics exigem `dashboard.read`, indisponível por chave) |
| `GET` `POST` | `/assets` | `asset.list` / `asset.create` |
| `GET` `POST` | `/urls` | `url.list` / `url.create` |
| `GET` | `/ads-manager/:projectId/*` | `ads-manager.read` |
| `POST` `PATCH` `DELETE` | `/ads-manager/:projectId/*` | `ads-manager.update` (exceto OAuth Meta: `auth-url` e `callback`) |

Os corpos e respostas dessas rotas são os mesmos usados pelo painel. As rotas de ingestão abaixo retornam `201` em caso de sucesso.

## Log de requisições

Toda requisição feita com chave fica registrada (método, caminho, status, duração, IP, corpo da requisição e da resposta com segredos mascarados) e pode ser consultada em **Configurações → Chaves de API → histórico**.

## POST /visitors

Cria um visitante no projeto. Permissão: `visitor.create`.

### Corpo da requisição

| Campo | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `projectId` | string | ver [Escopo de projetos](#escopo-de-projetos) | ID do projeto |
| `utmSource` | string | não | Origem UTM |
| `utmMedium` | string | não | Meio UTM |
| `utmCampaign` | string | não | Campanha UTM |
| `utmTerm` | string | não | Termo UTM |
| `utmContent` | string | não | Conteúdo UTM |
| `clickId` | string | não | ID de clique |
| `name` | string | não | Nome |
| `email` | string | não | E-mail |
| `phone` | string | não | Telefone |
| `addressStreet` | string | não | Rua |
| `addressCity` | string | não | Cidade |
| `addressState` | string | não | Estado |
| `addressZip` | string | não | CEP |
| `addressCountry` | string | não | País |

### Resposta

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `id` | string | ID do visitante |
| `createdAt` | string | Data de criação (ISO 8601) |
| `name` | string \| null | Nome |
| `email` | string \| null | E-mail |
| `phone` | string \| null | Telefone |
| `address` | object | Endereço |
| `address.street` | string \| null | Rua |
| `address.city` | string \| null | Cidade |
| `address.state` | string \| null | Estado |
| `address.zip` | string \| null | CEP |
| `address.country` | string \| null | País |
| `utmSource` | string | Origem UTM |
| `utmMedium` | string | Meio UTM |
| `utmCampaign` | string | Campanha UTM |
| `clickId` | string | ID de clique |

### Exemplo

```bash
curl -X POST 'https://dash-api.trackup.me/v1/visitors' \
  -H 'Content-Type: application/json' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -d '{
    "name": "Maria Silva",
    "email": "maria@example.com",
    "utmSource": "google",
    "utmCampaign": "black-friday"
  }'
```

## POST /conversions

Registra uma conversão no projeto. Permissão: `conversion.create`.

O campo `value` é convertido para a moeda configurada no projeto.

Se `transactionId` já existir com o mesmo status, a resposta é `409` e nada é duplicado. Envie sempre o `transactionId` para que reenvios sejam seguros.

`POST /refunds` e `POST /chargebacks` aceitam o mesmo corpo e registram, respectivamente, um reembolso e um chargeback (mesma permissão).

### Corpo da requisição

| Campo | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `projectId` | string | ver [Escopo de projetos](#escopo-de-projetos) | ID do projeto |
| `value` | number | **sim** | Valor da conversão |
| `transactionId` | string | não | ID da transação |
| `currency` | string | não | Moeda de origem (ex.: `BRL`, `USD`) |
| `paymentMethod` | string | não | Método de pagamento |
| `ip` | string | não | Endereço IP |
| `userAgent` | string | não | User agent |
| `visitorId` | string | não | ID do visitante |
| `trafficSource` | string | não | Fonte de tráfego |
| `utmSource` | string | não | Origem UTM |
| `utmMedium` | string | não | Meio UTM |
| `utmCampaign` | string | não | Campanha UTM |
| `utmTerm` | string | não | Termo UTM |
| `utmContent` | string | não | Conteúdo UTM |
| `clickId` | string | não | ID de clique |
| `sub1` | string | não | Sub ID 1 |
| `sub2` | string | não | Sub ID 2 |
| `sub3` | string | não | Sub ID 3 |
| `sub4` | string | não | Sub ID 4 |
| `sub5` | string | não | Sub ID 5 |
| `sub6` | string | não | Sub ID 6 |
| `sub7` | string | não | Sub ID 7 |
| `sub8` | string | não | Sub ID 8 |
| `status` | string | não | Status da conversão (padrão: `"paid"`) — ver valores abaixo |

Valores aceitos para `status`:

| Valor | Descrição |
| --- | --- |
| `paid` | Pagamento confirmado (padrão) |
| `refunded` | Reembolso |
| `chargeback` | Chargeback |

### Resposta

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `id` | string | ID da conversão |
| `timestamp` | string | Data/hora (ISO 8601) |
| `transactionId` | string | ID da transação |
| `value` | number | Valor convertido |
| `currency` | string | Moeda do projeto |
| `paymentMethod` | string | Método de pagamento |
| `status` | string | Status da conversão |
| `visitorId` | string | ID do visitante |

### Exemplo

```bash
curl -X POST 'https://dash-api.trackup.me/v1/conversions' \
  -H 'Content-Type: application/json' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -d '{
    "value": 199.90,
    "currency": "BRL",
    "transactionId": "txn_abc123",
    "visitorId": "aaaaaaaa-bbbb-4ccc-8ddd-eeeeeeeeeeee"
  }'
```

## POST /requests

Registra um evento ou requisição no projeto. Permissão: `request.create`.

Requisições criadas via API Key não disparam triggers ou pixels — apenas persistem o registro.

### Corpo da requisição

| Campo | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `projectId` | string | ver [Escopo de projetos](#escopo-de-projetos) | ID do projeto |
| `host` | string | não | Host da requisição (padrão: `""`) |
| `path` | string | não | Caminho da requisição (padrão: `""`) |
| `event` | string | não | Nome do evento (padrão: `""`) |
| `ip` | string | não | Endereço IP |
| `userAgent` | string | não | User agent |
| `visitorId` | string | não | ID do visitante |
| `trafficSource` | string | não | Fonte de tráfego (padrão: `"direct"`) |
| `utmSource` | string | não | Origem UTM |
| `utmMedium` | string | não | Meio UTM |
| `utmCampaign` | string | não | Campanha UTM |
| `utmTerm` | string | não | Termo UTM |
| `utmContent` | string | não | Conteúdo UTM |
| `clickId` | string | não | ID de clique |
| `sub1`–`sub8` | string | não | Sub IDs 1 a 8 |
| `customData` | object | não | Dados customizados (ver abaixo) |

### customData

Objeto plano com pares chave-valor.

| Regra | Valor |
| --- | --- |
| Máximo de chaves | 15 |
| Tamanho máximo | 8 KB (JSON serializado) |
| Violação | Resposta `422` |

Valores aninhados são permitidos. Se omitido, armazena `{}`.

### Resposta

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `id` | string | ID da requisição |
| `timestamp` | string | Data/hora (ISO 8601) |
| `host` | string | Host |
| `path` | string | Caminho |
| `event` | string | Nome do evento |
| `visitorId` | string | ID do visitante |
| `trafficSource` | string | Fonte de tráfego |
| `utmSource` | string | Origem UTM |
| `utmMedium` | string | Meio UTM |
| `utmCampaign` | string | Campanha UTM |
| `utmTerm` | string | Termo UTM |
| `utmContent` | string | Conteúdo UTM |
| `clickId` | string | ID de clique |
| `sub1`–`sub8` | string | Sub IDs 1 a 8 |
| `customData` | object \| null | Dados customizados |

### Exemplo

```bash
curl -X POST 'https://dash-api.trackup.me/v1/requests' \
  -H 'Content-Type: application/json' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -d '{
    "event": "purchase",
    "host": "loja.example.com",
    "path": "/checkout/success",
    "visitorId": "aaaaaaaa-bbbb-4ccc-8ddd-eeeeeeeeeeee",
    "customData": {
      "orderId": "ord_123",
      "value": 299.90
    }
  }'
```

## Erros

| Status | Causa |
| --- | --- |
| `400` | `projectId` ausente quando obrigatório |
| `401` | API Key ausente ou inválida |
| `403` | API Key revogada, expirada ou sem a permissão da rota |
| `404` | Projeto não encontrado ou fora do escopo da chave |
| `409` | `transactionId` já registrado com o mesmo status (`POST /conversions`, `/refunds`, `/chargebacks`) |
| `422` | Corpo inválido ou `customData` fora dos limites |
| `500` | Falha ao persistir o registro |
| `502` | Falha na conversão de moeda (`POST /conversions`) |
