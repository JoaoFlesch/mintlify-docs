Páginas criadas no Trackup já são rastreadas. Instale o script quando a página estiver em outro servidor (WordPress, Shopify, seu próprio site) ou quando quiser enviar eventos além do page_view.

Instalação

No painel, vá em Ajustes › Geral e, na seção Segurança, copie o Snippet de rastreamento. Ele já vem com o domínio e o ID do seu projeto.

Cole o snippet antes de </head> em todas as páginas que você quer rastrear.

Ainda em Ajustes › Geral › Segurança, adicione o domínio do site em Domínios permitidos. Use exemplo.com para o domínio raiz e *.exemplo.com para os subdomínios. Com a lista vazia, qualquer domínio pode enviar eventos.

Abra a página e confira a visita em Logs › Requisições.

O script carrega de https://{hostname}/__t/e.js e envia os eventos para POST /__t/events no mesmo domínio. Ele expõe a função global trackup com três comandos: init, track e identify. Chamadas feitas antes do carregamento ficam em fila e rodam depois do init.

Opções do init

trackup('init', '{projectId}', { passthrough: true, // repassa a query string para links decorados (padrão: true) registrable: 'exemplo.com' // domínio registrável, usado em links entre domínios });

Eventos customizados

Use track com qualquer nome de evento. Eventos diferentes de page_view são gravados como tipo customizado e podem ser usados como condição em acionadores.

trackup('track', 'sign_in'); trackup('track', 'add_to_cart', { customData: { productId: 'sku_42', quantity: 2 } });

Só o nome do evento e os dados de rastreamento automáticos (URL, UTMs, subs) são gravados. Propriedades soltas no terceiro argumento são ignoradas: use customData.

Pelo HTML, sem JavaScript

Adicione data-trackup-event a qualquer elemento clicável. Para enviar dados, use data-trackup-props com um JSON.

Comprar agora

Eventos enviados por atributo usam beacon: não aceitam callback e não disparam acionadores no navegador. Para isso, use trackup('track', …).

Callback

Passe uma função como quarto argumento para esperar a confirmação do servidor, por exemplo antes de redirecionar ao checkout.

document.getElementById('comprar').addEventListener('click', function (e) { e.preventDefault(); var destino = this.href; trackup('track', 'start_checkout', { value: '100', currency: 'BRL' }, function (event) { window.location.href = destino; // event.vid e event.sid disponíveis }); });
CampoDescrição
vidID do visitante (UUID), também salvo em cookie e localStorage.
sidID de atribuição da sessão, usado para decorar links.

O callback só roda quando o servidor responde 200. Se a navegação depende dele, use um timeout de segurança.

Identificar o visitante

identify grava dados de contato no perfil do visitante. Campos omitidos não apagam valores existentes.

trackup('identify', { name: 'Maria Silva', email: 'maria@exemplo.com', phone: '+5511999990000', addr_city: 'São Paulo', addr_state: 'SP', addr_country: 'BR' });
CampoDescrição
nameNome
emailE-mail
phoneTelefone
addr_street, addr_city, addr_state, addr_zip, addr_countryEndereço

Limites do customData

RegraValor
Chavesaté 15
Tamanhoaté 8 KB em JSON
Formatoobjeto plano (não array)

No script, um customData inválido é descartado e o evento segue sem ele. Na API, a mesma violação retorna 400.
