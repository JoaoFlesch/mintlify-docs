Sua página de vendas já está no ar em outro lugar, como WordPress, Elementor, Webflow ou Framer. Neste tutorial você faz o tráfego passar pelo Trackup, instala o script e envia eventos do funil sem mudar de hospedagem.

O que você vai precisar

  • Acesso para editar o <head> do site (tema, plugin de scripts ou configurações da plataforma).
  • Uma oferta criada no Trackup.

1. Instale o script

No Trackup, vá em Ajustes › Geral, seção Segurança, e copie o Snippet de rastreamento.

Instale um plugin de inserção de código no cabeçalho (como WPCode) e cole o snippet na área Header. Ou cole em header.php, antes de </head>.

Em Elementor › Custom Code, adicione um código com localização <head>, cole o snippet e publique para todo o site.

Em Site settings › Custom code › Head code, cole o snippet e publique.

Cole o snippet antes de </head> em todas as páginas.

Em Ajustes › Geral › Segurança, adicione o domínio do site (como www.seusite.com) em Domínios permitidos. Sem isso, os eventos são recusados.

2. Faça o tráfego passar pelo Trackup

Crie uma página Redirect que leva ao seu site. O anúncio aponta para ela. Assim o Trackup aplica o filtro, registra o clique e repassa as UTMs.

Em Páginas › Adicionar página, na aba Redirect: nome Site Curso, URL de redirecionamento https://www.seusite.com/curso, caminho /curso, Status Code 302.

Use o link dessa página (https://lp.seudominio.com/curso) com os parâmetros da fonte de tráfego no anúncio.

Se o anúncio apontar direto para o seu site, o script ainda registra as visitas e as UTMs, mas o filtro não atua, porque a requisição não passa pelo domínio do Trackup.

3. Ligue os botões à oferta

Troque o link de todos os botões de compra do site pelo link da oferta no Trackup, como https://lp.seudominio.com/checkout. No Elementor, edite cada botão e cole o link em Link.

4. Envie eventos do funil (opcional)

Marque ações importantes para usar em acionadores e no funil do dashboard. Pelo HTML, sem JavaScript:

Quero me inscrever

Ou pelo JavaScript, por exemplo quando o vídeo chega ao pitch:

trackup('track', 'vsl_pitch');

Para mandar um evento para o pixel, crie um acionador com a condição Tipo customizado igual ao nome do evento.

5. Valide

Abra https://lp.seudominio.com/curso?utm_source=teste em uma aba anônima. Você deve cair no seu site com utm_source=teste na URL.

Em Logs › Requisições, aparecem o acesso ao link e o page_view enviado pelo script, no mesmo visitante.

O checkout deve abrir com o parâmetro de clique da plataforma (como sck ou src) na URL.

Problemas comuns

O domínio do site não está em Domínios permitidos, o snippet não está no <head>, ou um plugin de cache serve uma versão antiga. Limpe o cache e confira o código-fonte da página.

Algum redirecionamento do site (como de seusite.com para www.seusite.com) está removendo a query string. Use na página Redirect a URL final, já com www e barra.
