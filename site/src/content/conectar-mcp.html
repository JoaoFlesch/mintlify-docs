--- title: Conectar ao MCP icon: plug description: Conecte Claude, ChatGPT, Cursor e outros assistentes ao Trackup e opere seus projetos conversando. ---

O MCP (Model Context Protocol) é o padrão que deixa um assistente de IA usar ferramentas externas. Com o servidor MCP do Trackup, o assistente lista projetos, cria páginas e links, lê métricas e ajusta campanhas, sempre dentro das permissões que você der.

URL do servidor

Cada time tem a sua URL. Copie a do seu time em Configurações › MCP. O formato é:

https://api.trackup.me/SEU_TEAM_ID/mcp

Atalho: em Configurações › MCP, clique em Copiar prompt para o agente e cole no seu assistente. Ele adiciona o servidor sozinho e explica como autorizar.

Para conectar um assistente, você precisa da permissão Criar em API Keys (MCP). Se não tiver, peça ao proprietário do time para liberar em Membros.

Conectar

Em Configurações › MCP, escolha as permissões e os projetos e clique em Salvar configuração. Ela vem preenchida na tela de autorização e vale por 24 horas.

No Claude.ai ou no Claude Desktop, abra Configurações › Conectores, clique em Adicionar e escolha Adicionar conector personalizado.

Dê o nome Trackup, cole a URL do servidor do seu time e clique em Continuar.

O Trackup abre no navegador. Confira o time, as permissões e os projetos e clique em Autorizar.

Nas configurações do ChatGPT, ative o Modo desenvolvedor. A disponibilidade depende do seu plano.

Crie um conector MCP personalizado com a URL do servidor do seu time e autenticação OAuth.

Confira time, permissões e projetos e clique em Autorizar.

Com OAuth:

claude mcp add --transport http trackup https://api.trackup.me/SEU_TEAM_ID/mcp

Depois rode /mcp, escolha o servidor e Authenticate. Com chave de API:

claude mcp add --transport http trackup https://api.trackup.me/SEU_TEAM_ID/mcp \ --header "X-Api-Key: SUA_CHAVE"

Em Configurações › MCP, escolha Prefiro usar uma chave de API, crie a chave e clique em Instalar no Cursor. Para configurar à mão, edite ~/.cursor/mcp.json:

{ "mcpServers": { "trackup": { "url": "https://api.trackup.me/SEU_TEAM_ID/mcp", "headers": { "X-Api-Key": "SUA_CHAVE" } } } }

Use Instalar no VS Code em Configurações › MCP, ou edite .vscode/mcp.json:

{ "servers": { "trackup": { "type": "http", "url": "https://api.trackup.me/SEU_TEAM_ID/mcp", "headers": { "X-Api-Key": "SUA_CHAVE" } } } }

Qualquer cliente MCP com transporte Streamable HTTP funciona. Envie a chave no header X-Api-Key. Para testar e listar as ferramentas:

curl -X POST "https://api.trackup.me/SEU_TEAM_ID/mcp" \ -H "Content-Type: application/json" \ -H "Accept: application/json, text/event-stream" \ -H "X-Api-Key: SUA_CHAVE" \ -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

O que o assistente consegue fazer

Cada ferramenta corresponde a uma operação da API. Projetos, analytics, páginas e links aparecem como ferramentas diretas. Pixels, acionadores, domínios, dashboards, gerenciador de anúncios, plataformas de venda, fontes de tráfego e filtro são acessados por ferramentas de busca de operações.

Visão geral do projeto, conversões, visitantes, requisições e dashboards. Montar páginas no Builder, clonar sites, editar arquivos e publicar. Pixels com acionadores, links, testes A/B, domínios e regras de filtro. Ler o Gerenciador de anúncios, pausar e ajustar orçamentos.

O assistente não acessa cobrança, membros, gestão de chaves, exclusão de projeto nem conexões OAuth (Meta, Nuvemshop).

Exemplos de pedidos

  • "Liste meus projetos no Trackup."
  • "Quantas conversões o projeto Loja teve nesta semana, por fonte de tráfego?"
  • "Crie um link /oferta-natal apontando para a página Oferta de Natal."
  • "Monte uma landing page para o meu curso de inglês e publique."
  • "Quais anúncios gastaram mais de R$ 200 ontem sem vender?"

Segurança

  • Dê só o necessário. Restrinja permissões e projetos na autorização.
  • Publicar muda o que está no ar. O assistente pede confirmação antes de republicar uma página editada ou publicar o projeto.
  • Tudo fica registrado. Cada chamada aparece em Chaves de API › Ver histórico, marcada como MCP.
  • Desconectar é revogar. Revogue a chave e o acesso termina na hora.
