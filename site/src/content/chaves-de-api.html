--- title: Chaves de API icon: key description: Crie chaves para integrar sistemas e agentes de IA ao Trackup, com permissões e projetos limitados. ---

Uma chave de API dá acesso à API do Trackup e ao servidor MCP em nome do time. Cada chave tem suas permissões, seus projetos e, se quiser, uma data de validade.

Criar uma chave

Clique no seu nome, no canto inferior esquerdo, e abra Configurações. Em Meu Time, selecione Chaves de API e clique em Nova chave. Você precisa da permissão Criar em API Keys; sem ela, peça ao proprietário do time.
CampoDescrição
NomeOnde a chave será usada, como Automação produção.
Expira emOpcional. Depois da data, a chave para de funcionar.
ProjetosVazio dá acesso a todos os projetos do time. Escolha só os necessários.
PermissõesO que a chave pode fazer, por recurso: listar, ler, criar, atualizar e deletar.

Clique em Criar. A chave completa aparece uma única vez. Copie e guarde em um gerenciador de senhas ou nas variáveis de ambiente do seu sistema.

Uma chave nunca pode mais do que quem a criou. Se o criador perder uma permissão ou sair do time, a chave perde junto. A exceção são as permissões de ingestão (visitor.create, conversion.create e request.create), que são exclusivas de chaves.

Exemplos de permissões

UsoPermissões mínimas
Enviar vendas de um CRM ou checkoutconversion.create
Relatóriosproject.list, analytics.read, conversion.list
Assistente de IA que monta páginas e linksPermissões de page e link (listar, ler, criar, atualizar)

Usar a chave

Envie a chave no header X-Api-Key. A URL base aparece na própria tela, em URL da API. Chave ausente, inválida, revogada ou expirada retorna 403 na API REST e 401 no MCP.

curl https://api.trackup.me/v1/projects \ -H "X-Api-Key: $TRACKUP_API_KEY"

Histórico de uso

No menu da chave, clique em Ver histórico. Você vê cada requisição feita com ela: método, caminho, status HTTP, IP, duração e a origem (API ou MCP, com o nome da ferramenta). Os corpos aparecem com os segredos mascarados.

Editar e revogar

  • Editar, no menu da chave, muda nome, permissões e projetos sem trocar a chave.
  • Revogar, no menu da chave, desativa a chave na hora. Não dá para desfazer.

Se uma chave vazar, revogue e crie outra. Não compartilhe chaves em prints, repositórios ou mensagens.
