--- title: Autenticação icon: key description: Autentique as requisições com uma chave de API do time. ---

Toda requisição precisa do header X-Api-Key com uma chave de API.

curl https://api.trackup.me/v1/projects \ -H "X-Api-Key: $TRACKUP_API_KEY"

Time

Cada chave pertence a um time. Não é preciso enviar X-Team-Id. Se enviar, ele precisa ser o time da chave.

Permissões

Cada endpoint exige uma permissão, indicada na página dele, no formato recurso.ação, como page.create ou conversion.list. As ações são list, read, create, update e delete.

  • A chave só faz o que quem a criou pode fazer no time. Se essa pessoa perder a permissão ou sair do time, a chave perde junto.
  • As permissões de ingestão visitor.create, conversion.create e request.create são exclusivas de chaves e não dependem das permissões de quem criou.

Projetos

Uma chave acessa todos os projetos do time ou só os escolhidos na criação. Pedidos a um projeto fora da lista respondem 404.

Validade e revogação

Depois da data de validade, ou depois de revogada, a chave responde 403.

Use a chave só no servidor. Nunca coloque a chave em código que roda no navegador, em aplicativos ou em repositórios.
