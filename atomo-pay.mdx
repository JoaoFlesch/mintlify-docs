# Passo 2 — Selecionar Átomo Pay e configurar parâmetros de tracking

Agora você precisará configurar quais informações serão enviadas junto com o checkout.

Esses parâmetros permitem manter toda atribuição da campanha durante a jornada do usuário.

Exemplo:

```text
sck={request.id}

utm_source={request.utmSource}

utm_medium={request.utmMedium}

utm_campaign={request.utmCampaign}

utm_content={request.utmContent}
```

Esses valores serão preenchidos automaticamente pelo Trackup.

---

### O que cada parâmetro significa?

| Parâmetro | Função |
| :-- | :-- |
| sck | Identificador único da sessão |
| utm\_source | Origem do tráfego |
| utm\_medium | Conjunto ou mídia |
| utm\_campaign | Nome da campanha |
| utm\_content | Criativo responsável |

# Passo 4 — Copiar o Webhook gerado

Toda integração gera automaticamente um endpoint exclusivo para receber notificações de venda.

Exemplo:

```text
Webhook URL

https://Trackup.me/api/webhook/xxxxxxxxxxxx
```

Copie essa URL.

Você precisará inseri-la dentro da plataforma.

# Passo 5 — Configurar o Webhook dentro da Átomo Pay

Agora acesse o painel da Átomo Pay.

Localize a área responsável por notificações, integrações ou webhooks.

Cole a URL gerada pelo Trackup.

Fluxo esperado:

```text
Átomo Pay
↓
Integrações/Webhooks
↓
Adicionar
↓
Colar URL do Trackup
↓
Selecione os Produtos
↓
Marque todos métodos de Pagamento
↓
Marque os Status de Pagamento (Pago, Reembolsado, Chargeback)
↓
Salve
```

# Passo 6 — Realizar um teste de compra

Após finalizar a configuração, recomendamos realizar uma compra teste.\
Isso permite validar se o Trackup está recebendo corretamente os dados da venda.

Fluxo:

```text
Criar checkout teste
↓
Realizar pagamento
↓
Aguardar webhook
↓
Verificar conversão no painel
```

---

# Como validar se está funcionando?

Após uma venda teste, acesse:

```text
Projeto → Logs → Conversões
```

Se tudo estiver correto, você verá:

```text
Valor da venda

Gateway utilizado

Origem da campanha

UTMs recebidas

Click ID registrado

Visitor associado
```

Exemplo:

```text
R$ 47,90

Facebook

Campaign: Teste Produto 01

Status: Sucesso
```
