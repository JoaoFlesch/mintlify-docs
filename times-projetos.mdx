### Entenda como organizar suas operações dentro do Trackup.

Toda a estrutura do Trackup foi criada para permitir que você organize sua operação de forma escalável, colaborativa e bem estruturada.

Antes de começar a criar páginas, campanhas ou links, é importante entender como a plataforma organiza seus recursos.

No Trackup, tudo funciona a partir de uma estrutura central composta por:

- Times
- Projetos
- Membros

Essa arquitetura foi pensada para permitir que múltiplas pessoas trabalhem na mesma operação de forma organizada.

# O que é um Time?

O Time representa o ambiente principal da sua operação dentro do Trackup.

Pense nele como sua empresa, sua operação ou seu workspace principal.

É dentro do Time que você centraliza tudo que faz parte daquela estrutura.

Cada Time possui:

- Seus próprios membros
- Seus próprios projetos
- Sua assinatura ativa
- Seus limites de uso

Em resumo:

> O Time é o ambiente principal que organiza toda sua operação.

Cada Time funciona como uma estrutura independente.

# O que são Membros?

Membros são os usuários que possuem acesso a um determinado Time.

Todo membro pertence ao Time.

Isso significa que ele poderá colaborar em toda estrutura existente dentro daquele ambiente.

Exemplo:

Dentro de um Time você pode adicionar:

- Sócios
- Gestores de tráfego
- Designers
- Desenvolvedores

Esses membros compartilham acesso ao mesmo ambiente.

---

# O que é um Projeto?

Projetos são operações individuais criadas dentro de um Time.

Cada Projeto representa uma estrutura independente dentro daquele ambiente.

Recomendamos utilizar um Projeto para cada:

- Produto
- Funil
- Oferta principal
- Operação específica

O objetivo é manter cada operação organizada separadamente.

---

### Exemplo

```text
Time → Upsurge

Projetos

Projeto 1 → Trackup  
Projeto 2 → Cloakup
Projeto 3 → Upag
```

# O que fica dentro de um Projeto?

Todo recurso operacional do Trackup fica vinculado a um Projeto específico.

```text
Projeto
├── Gerenciador de Anúncios
├── Ofertas
├── Páginas
├── Links
├── Acionadores
├── Filtros
├── Logs
└── Integrações
```

# Como recomendamos organizar sua estrutura

A organização correta depende do seu modelo de operação.

```text
Time → Sua operação principal

Membros

• Sócios  
• Gestores  
• Desenvolvedores

Projetos

• Produto principal  
• Oferta secundária  
• Ambiente de testes
```

Uma boa organização facilita escalabilidade no longo prazo.

---

### Se você é afiliado

Crie um Projeto para cada oferta.

```text
Time → João Performance

Projeto 1 → Produto Financeiro  
Projeto 2 → Produto Nutra  
Projeto 3 → Produto SaaS
```

---

### Se você possui agência

Crie um Projeto para cada cliente, se você for pagar a assinatura de cada cliente, caso venha a repassar os custos recomendamos que faça um time para cada cliente.

```text
Time → Atlas Agency

Projeto 1 → Cliente A  
Projeto 2 → Cliente B  
Projeto 3 → Cliente C
```

# Limites por plano

Cada Time possui limites definidos pelo plano contratado.

Esses limites podem incluir:

- Quantidade máxima de projetos
- Quantidade máxima de membros
- Recursos disponíveis
- Limites operacionais

Os limites variam de acordo com sua assinatura ativa.
