Cada fluxo mostra as permissões, as chamadas em ordem e o que fazer com a resposta. Os exemplos usam https://api.trackup.me/v1 e a chave em $TRACKUP_API_KEY. Antes, configure a chave como em Agentes de IA.

Registrar vendas de um CRM ou checkout

Cada venda confirmada no seu sistema vira uma conversão no Trackup, atribuída ao visitante certo.

Para atribuir a venda, envie o visitorId que o Trackup gerou quando a pessoa passou pela sua página. Guarde esse ID no CRM junto com o lead. Sem ele, envie o que tiver: clickId, UTMs ou trafficSource.

 curl -X POST https://api.trackup.me/v1/conversions \ -H "Content-Type: application/json" \ -H "X-Api-Key: $TRACKUP_API_KEY" \ -d '{ "projectId": "PROJECT_ID", "transactionId": "crm-98213", "value": 497.00, "currency": "BRL", "paymentMethod": "pix", "visitorId": "VISITOR_ID" }'

Sempre envie transactionId. Se a chamada se repetir, o Trackup responde 409 e não duplica a venda.

Mesmo corpo e mesmo transactionId, em POST /v1/refunds ou POST /v1/chargebacks.

Relatório diário

curl https://api.trackup.me/v1/projects -H "X-Api-Key: $TRACKUP_API_KEY" curl "https://api.trackup.me/v1/projects/PROJECT_ID/analytics/overview?startDate=2026-11-11&endDate=2026-11-11&granularity=hour" \ -H "X-Api-Key: $TRACKUP_API_KEY"

Datas no formato YYYY-MM-DD, no fuso do time. A resposta traz requisições, visitantes únicos, conversões, receita, ticket médio e as séries ao longo do período.

 curl "https://api.trackup.me/v1/projects/PROJECT_ID/conversions?startDate=2026-11-11&endDate=2026-11-11&limit=100" \ -H "X-Api-Key: $TRACKUP_API_KEY"

Use page para buscar as próximas páginas até somar count.

 Loja · 11/11 Visitantes únicos: 9.912 · Conversões: 143 · Receita: R$ 71.051,00 Principal fonte: meta (61% da receita)

Controlar campanhas de anúncios

Pré-requisito: conta de anúncios conectada no Gerenciador de anúncios. A conexão é feita por uma pessoa no painel; chaves de API não conectam contas.

curl https://api.trackup.me/v1/ads-manager/PROJECT_ID/accounts -H "X-Api-Key: $TRACKUP_API_KEY" curl "https://api.trackup.me/v1/ads-manager/PROJECT_ID/table?accountIds=ACCOUNT_ID&level=campaign&startDate=2026-11-11&endDate=2026-11-11" \ -H "X-Api-Key: $TRACKUP_API_KEY"

level aceita campaign, adset ou ad. Cada linha traz investimento, vendas, receita, ROAS e CPA.

 curl -X PATCH https://api.trackup.me/v1/ads-manager/PROJECT_ID/entities/ENTITY_ID/status \ -H "Content-Type: application/json" \ -H "X-Api-Key: $TRACKUP_API_KEY" \ -d '{ "entityType": "campaign", "status": "PAUSED" }'

Para orçamento, use /entities/ENTITY_ID/budget. Veja os campos em Atualizar orçamento.

Pausar e mudar orçamento mexe em dinheiro real. Faça o agente pedir confirmação a uma pessoa, ou dê só ads-manager.read.

Auditar tráfego

curl -G https://api.trackup.me/v1/projects/PROJECT_ID/requests \ -H "X-Api-Key: $TRACKUP_API_KEY" \ --data-urlencode "startDate=2026-11-11" \ --data-urlencode "endDate=2026-11-11" \ --data-urlencode 'filters=[{"field":"country","operator":"not_equals","value":"BR"}]' curl https://api.trackup.me/v1/projects/PROJECT_ID/requests/REQUEST_ID/logs -H "X-Api-Key: $TRACKUP_API_KEY" curl https://api.trackup.me/v1/projects/PROJECT_ID/visitors/VISITOR_ID/events -H "X-Api-Key: $TRACKUP_API_KEY"
